# 仓库登录与选择入口

入口依据 `Design/GHS_Twin_SaaS_Concept/Saas.pen` 的 60（企业登录）和 61（仓库卡片选择）页面实现，采用原设计的深蓝顶栏、仓库主视觉、白色登录侧栏和浅色卡片目录。

## 使用流程

1. 程序启动进入登录页，点击「登录」直接进入仓库选择。账号、密码均可留空，输入内容不会读取、保存或发送。
2. 目录只展示已接入的 GHS 加州仓库和 MPR 新泽西仓库，可按名称、地址或地区筛选。
3. 点击卡片后保留仓库选择页，仓库及界面准备好后显示场景，播放原有约 1.6 秒的进入相机过渡。没有整屏加载页或顶部加载提示条，加载期间可按 Esc 取消。仓库地图、地址、缩略图和 MPR 默认相机均使用现有 `warehouses.json`。
4. 仓库内点击左下角「返回仓库选择」切换仓库。当前页面会保留选择态，不要求再次登录；「返回登录」可回到首页。

登录只负责页面导航，本次未实现账号管理、身份认证、权限或账号持久化。像素流服务原有的接入控制不属于此页面的登录功能。

## 实现与动效

- 默认启动地图为 `/Game/Maps/GHS_WarehousePortal`，仅承载页面和仓库流送控制器，没有地球、国家标签或 POI。编辑器默认打开的地图不随此功能改变。
- `entry.html`、`entry.css`、`entry.js` 由 UE 的 CEF 界面统一加载，本机程序和像素流画面使用同一实现。原控制器继续管理目的地加载、相机、HUD、屋顶和退出释放。
- 加载期间保留完整、不透明的仓库选择页；原生确认仓库界面就绪、开始相机过渡时，通过 `transition.arrivalStarted` 立即揭开目录，不再等镜头运动结束。动画结束后才显示可操作的返回按钮。返回时直接显示选择页，不显示白色过渡层或独立等待页面。加载前仍等待完整目录的布局及浏览器绘制回执，避免加载中间画面露出。
- 使用 `ui-motion` 的 `buttons/button`、`cards/card`、`overlays/dialog` 和共享缓动：按钮按压 0.97 倍、卡片悬停上移 2px 并显示蓝色 2px 外环、封面 600ms 放大至 1.03 倍，登录和目录页面先退场再入场。描边不改变卡片尺寸。系统「减少动态效果」关闭位移、缩放和循环动画。
- 原全球地图保留；需查看旧入口时，显式启动 `/Game/Maps/GHS_GlobalWarehouse -LegacyGlobe`。
