# GPU 渲染优化验证（2026-10-29）

本轮保持 1920×1080、100% 屏幕比例、近景几何、材质、光照、阴影与交互；仅对三款地堆模型的远景 LOD2/3 做经验证的结构减面。以下数据来自 RTX 5060 Laptop 单个独立 Editor-game 进程，不代表阿里云服务器或三实例吞吐量。测量时取消帧率上限以分离 GPU 耗时；发行的像素流目标仍为 60 FPS。

## 采用的配置

1. Epic 抗锯齿使用 TSR History 150%，保留 TSR 的其他 Epic 设置和原生输入分辨率。200% 在多次新进程中出现昂贵的历史更新/Resolve 路径；另一次同进程切换又没有复现。150% 避开了已复现的高开销路径，屋顶、玻璃和步进旋转中的细小结构对照可接受，不能将单次结果表述成稳定节省 20 ms 或固定百分比。
2. `r.EarlyZPassOnlyMaterialMasking=1`：在当前已有完整深度预通道的条件下，将遮罩覆盖计算放到预通道，减少后续重复计算。需要重启并完整 Cook 着色器。屋顶溶解、货架/地堆容量 0/80/100%、玻璃、车辆和树木对照通过；测试的首次材质编译占位画面不作为正式画质结果。

EarlyZ 同一轮、相同二进制与 History150 的比较（每视角 600 帧，去掉首尾各 10 帧）：

| 视角 | 关闭时 GPU ms | 开启时 GPU ms | BasePass+PrePass 降幅 |
|---|---:|---:|---:|
| 闭顶首页 | 13.68 | 12.99 | 20.9% |
| 开顶全景 | 23.58 | 23.30 | 2.4% |
| 地堆预设 | 24.87 | 24.22 | 5.0% |
| 货架预设 | 24.38 | 23.18 | 6.2% |
| 追溯 | 21.60 | 21.12 | 5.9% |

这些毫秒数仅描述本轮机器状态。不同轮的供电/热状态和 GPU 后台工作有差异，不能跨轮直接相减。完整原始数据位于 `Saved/GPUOptimization/EarlyZMaskExperiment/comparison.json`、`depth_20261029_132806`、`depth_20261029_133431`；预热后的屋顶复查位于 `baseline_20261029_134234`。

## 拒绝的实验与验证边界

- 屋顶闭合时手动关闭内部实例主通道：实际 GPU/DrawCalls 未显示可靠收益，已撤回，避免维护额外状态。
- 容量遮罩的顶点化：收益不可靠，未修改正式材质。
- 当前启用的全局后处理覆盖将 Lumen GI/反射设为 None；GPU pass 与运行时 PP 检查一致，未启用 Lumen。
- 原生回归测试 13 项通过，涵盖完整货物/托盘 LOD、屋顶生命周期/选择/溶解、像素流运行时。编译通过不替代打包后的运行和浏览器验证。

复测方法见 `Scripts/ghs/gpu_baseline_README.md`。所有 GPU 进程串行运行，使用隔离构建且禁用 StarterContent 自动导入，保留用户编辑器及手动地图修改。服务器最终收益必须结合打包后 GPU/GT/RT/RHI 与三个可见浏览器窗口的帧率、解码、缓冲、丢包和卡顿增量另行记录。
