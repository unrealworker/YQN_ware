# GHS 道路标线稳定性验证

远处车道白线投影不足一个像素时，覆盖率随帧变化，表现为闪烁。此次仅为源道路生成器中可逐面匹配的标线增加专用材质；不足 1.15 像素时平面扩展并补偿颜色，近景保持原宽度及颜色。道路端部原有的渐隐保留。前后帧分别计算投影，限制最大平面扩展 45 厘米；不改变高度、路面或碰撞。

三个正式网格共匹配 33,012 个三角面：园区标线 16,004、追溯停车场替代网格 16,004、道路延伸末端 1,004。非道路面继续使用原材质，不包括车辆、窗户及停车位图案。三个网格均只有一个细节级。新进程重新加载后，材质分段、额外 UV、原顶点/法线/UV0 指纹及碰撞数据均通过核对，重复应用通过。

## 实机结果

1920×1080 下，450 米距离、俯角 33°，北侧和西侧各取 12 段实际白线。每组固定及缓移各 10 帧，冻结车辆，同轨隐藏白线作为背景对照。表内数值为白线峰值亮度的时间标准差，亮度范围 0–255。

| 方向与镜头 | 原材质，100% 输入 | 新材质，100% 输入 | 新材质，引擎自动输入 |
| --- | ---: | ---: | ---: |
| 北侧固定 | 2.72 | 0.27 | 0.21 |
| 北侧缓移 | 4.26 | 0.28 | 0.27 |
| 西侧固定 | 1.58 | 0.21 | 0.18 |
| 西侧缓移 | 2.93 | 0.24 | 0.21 |

36 米近景对照中，北侧固定白线峰值亮度 83.55 → 83.53，西侧缓移 84.23 → 84.22，线宽和外观保持一致。远景通过略增加覆盖范围提高可见性，因此比原来断续的亚像素白线更清楚；不声称所有距离完全无闪烁。全局分辨率及抗锯齿设置未调整。

## 重新生成

使用 Blender 运行 `Scripts/ghs/road_marking_sources.py` 采集源道路带，再在 UE 编辑器命令程序内以 `-RoadApply` 执行 `Scripts/ghs/apply_road_marking_coverage.py`。工具逐面验证后调用仅编辑器可用的 `GHSRoadMarkingEditorLibrary` 增加专用 UV 和材质组。重新导入三个原网格后需要再次应用此步骤。运行前需编译本次编辑器模块，并关闭占用这些资产的其他编辑器。

本机原资产备份在 `Saved/GHSRenderQuality/RoadAssets/Before`。回退本次资源时同步回退三个网格和两个专用材质，不覆盖地图或其他场景资源。
