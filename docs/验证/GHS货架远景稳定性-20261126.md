# GHS 货架远景验收

八类正式货架使用新的 LOD2、LOD3。真机在 1920×1080、65° 视野、俯角 58° 下对比。每种状态分别拍固定镜头十帧和横移十帧，运行时对照后恢复八组组件。下面统计同一区域内相邻图像灰度差超过 12/255 的像素比例。横移按局部位移配准。

| 距离与渲染输入 | 固定镜头，原版 → 新版 | 缓慢横移，原版 → 新版 |
|---|---:|---:|
| 300 米，100% | 0.83% → 0.35% | 1.01% → 0.45% |
| 450 米全仓，100% | 0.33% → 0.23% | 0.53% → 0.37% |
| 450 米全仓，引擎自动 | 0.19% → 0.13% | 0.40% → 0.23% |

450 米自动组使用 r.ScreenPercentage=0，具体内部像素尺寸未逐帧记录。100% 组的局部边缘更清晰，固定镜头也保留了更多细微亮度变化。中景 103 米亮度均值变化小于 0.1/255，近景 34 米局部对比度差小于 0.02/255。剩余细线在相机运动中仍有少量闪动。

正式储存后用新进程重读八个资产，两级近景的顶点坐标、法线、主纹理坐标、索引和材质分段的签名逐项一致，七个材质槽与四个切换阈值相同。两级远景逐三角面核对了库位显隐编码，确保独立切换每个托位及货物。
