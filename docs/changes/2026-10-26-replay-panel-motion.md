# 追溯时间条与面板同步伸缩

收起侧面板时，时间条不再等到面板消失后突然变宽；展开时也从当前宽度连续收回。两者沿用同一条 420ms 面板动画曲线，中途反向从当前位置继续。

原先同时重设 CEF 浏览器尺寸和网页逻辑尺寸，会产生异步缩放和闪动。现在保持浏览器画布宽度稳定，以父 Canvas 的裁剪宽度控制显示及点击范围，并将同一原生宽度传给网页内容。字体不缩放；事件标记在动画期间保留节点，结束后再按最终宽度聚合。下拉菜单和 650/850 紧凑布局也使用实际可见宽度。

## 验证

- 修改前真实 UE 验证复现失败：侧面板已移动，时间条仍停在 1392px，CEF 也只有 1392px。
- TestEditor Win64 Development 编译通过，MSVC 14.38.33130。
- 网页测试 132 项通过，包含新增的连续布局、标记稳定、拖动保持、响应式边界与菜单裁剪回归。
- `Scripts/ghs/verify_replay_panel_motion.py` 在独立 UE 游戏实例中通过收起、展开、中途反向和场景恢复检查。真实 CEF 分别采集 25、24、34 个布局样本，画布始终为 1872px，字体始终为 12px；内容宽度连续跟随原生裁剪，回放状态不变。
- 在真实 CEF 中验证 851/850/651/650px 可见宽度，七个操作控件均在边界内；这项检查不等同于完整窄屏窗口验收。
