# 订单追溯替换与开发

2026-10-23。正式设计源：`Design/GHS_Twin_SaaS_Concept/Saas.pen`。

## 使用流程

1. 打开「追溯」，按仓库当地时间（America/Los_Angeles）选择至少一小时的时段。跨夏令时时按真实经过时长校验，重复时刻需明确偏移，不存在的时刻不可提交。
2. 索引测试订单，选择任意 `TEST-OUT-001` 至 `TEST-OUT-004` 后进入该时段的全设备回放。
3. 使用底部时间轴暂停、播放、前后跳转 30 秒、1–64 倍速，查看关键事件标记。可选择设备跟随，或切换回放全景、全部/选中/关闭轨迹。
4. 点击「结束追溯」或执行首页、页面导航、搜索定位、视角预设等操作时确认停止。取消保留回放进度和暂停状态；确认先恢复原场景，再执行原操作一次。

## 场景与数据

- 五台人工叉车、三辆装卸卡车、十个蓝底托盘；包含上下两层取货、货叉升降、载货运输、装车、关门出园、返程补给、回放故障事件。
- 测试循环长 2463 秒，包含 48 个关键事件。所有有效时间范围和测试订单共用同一组相对时刻数据；循环播放到用户选择的结束时间并暂停。这些不是实际业务轨迹。
- 原设备、充电桩、原车辆、停车场和周围住宅中的静态小车及路上交通在回放中隔离；退出后恢复原可见性、Tick、模型、实例变换、屋顶和相机。
- 模型复用现有场景资产，新增拆分资产位于 `/Game/GHSOrderReplay`；没有修改原有模型、用户手动摆放或地图文件。
- 动作、货物归属、事件及蓝色流动轨迹使用同一回放时间。拖动到任意时刻直接求值，不需要逐帧补算历史。回放对象池、事件窗口和时间轴标记均有固定上限。
- 正式设计替换原追溯板，并补齐时间校验、订单结果、播放、暂停、跟随、事件、结束及退出确认状态；保持现有蓝白灰视觉样式。
