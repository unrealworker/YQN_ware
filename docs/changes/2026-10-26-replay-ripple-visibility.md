# 追溯叉车扩散环可见度

叉车底部扩散环使用与轨迹相同的主题蓝渐变 `#8BB9FF → #356BFA`。主波纹核心宽度约 5.28cm，峰值透明度 0.96；通过底色覆盖配合 0.55 的适度自发光，在浅灰地面上保持清晰的蓝色，而不是接近白色的细线。

保留三层向外扩散和旋转弧线，周期 2 秒，仍使用回放时钟，暂停及拖动时间时同步。仅运动中的追溯叉车显示，路线关闭、故障静止、播放结束和退出追溯时隐藏。沿用原有五个 Decal 组件，不增加 Actor、组件或贴图。
