## EIP 修复前的历史网络检查

以下记录发生在 EIP 媒体地址修复前。当时本机网页与信令可通，视频接收 0 字节；独立定点测试确认当时被测私网 UDP 路径未通。**这些是历史结果，不能据此继续判断当前媒体不通。** 后续公网 EIP 候选的成功接收证据见上文。

网页和信令通过 HTTPS 链路传输，视频另经 WebRTC 媒体链路传输。能打开链接不单独证明视频候选地址可达；本次已另外通过 EIP 候选验证本机视频，不再只依赖服务器自身 Edge 的自测。
