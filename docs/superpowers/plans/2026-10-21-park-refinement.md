# 园区地图比对与精细化实施计划

**目标：** 按用户卫星图改进完整园区的比例、弧形道路、封闭围栏与住宅建筑，替换上一版粗糙模型。

**范围与授权：** 用户已要求直接制作并允许删除多余模型。原仓库业务设备、货架和已确认交互保留；仅替换 `GHSPark_` 所属环境网格。提交到本地 master，中文提交说明。

**实现：** 保持 CAD 仓库的米制坐标，以卫星图仓库角点校准道路和园区边界。`park_curves.py` 提供相切圆弧与弧长采样；`park_housing.py` 提供四种两层住宅；`build_park_geometry.py` 组合场地、连续路缘、门线、围栏、街区庭院和材质网格。后台 Blender 导出 FBX，经现有导入器更新当前场景。

- [ ] 比对地图并保存参考截图，检查当前地图无未保存修改，留存本次修改前备份。
- [ ] 修复道路断口、移开占路门卫，制作圆弧连接及连续标线，统一围栏和门口坐标。
- [ ] 替换简单人字顶房盒为有车库、四坡顶、太阳能、窗户、车道和庭院的住宅；移除侵路、重复与越界模型。
- [ ] 后台生成、几何校验，检查道路通达、围栏闭环及门口净宽、房屋净距、面数。
- [ ] 导入并保存 UE 当前地图；检查材质、比例、法线、总览及近景截图。
- [ ] 运行已有 1080p / 2560×1600 交互检查和保存后重载保留性检查；独立审查结果后中文提交。

**验收重点：** 弯道无折角与道路接缝；围栏没有意外缺口或横挡出入口；所有住宅车道朝向道路且不侵入道路；场地与背景有清晰层次；原始仓库 actor / 货架实例 / 设备注册数量不变化。地图属于基于卫星图和 CAD 尺寸的视觉重建，不视为实地测绘数据。
