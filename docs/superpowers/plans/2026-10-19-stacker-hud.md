# 电动堆高车 HUD 与快速聚合

目标：将已有 12 台电动堆高车接入紧凑 HUD，展示运行、待机、预警、故障、离线，消除聚合时标签横穿屏幕的动画。

延续现有原生 UMG/Slate、2×2 自适应分区与 Warehouse Camera 的 10000 cm 聚合阈值。混合区域显示设备总数，成员列表区分车型和状态。堆高车提供电量、货叉高度、任务，离线清空数值。演示标记独立于状态文本，真实遥测替换演示后不被重新发现覆盖。

- [x] 数据：新增独立堆高车组件与非法输入、离线恢复、演示保护测试。为场景原有堆高车保存稳定身份标签。
- [x] 界面：统一设备选择、投影和聚合，保留卡片 320×184 与标签 34 高度、车辆兼容接口；堆高车使用独立图标。
- [x] 动画：120 ms 局部淡入淡出，标签过渡位移不超过 8 逻辑像素；大距离重定位不进行长距离追赶。详情继续有开合过渡。
- [x] 验证：先在旧模块验证缺失接口；编译运行 GHS 自动化，真实场景验证 52 辆装卸车和 12 台堆高车、多状态、混合聚合、缩放阈值、点击详情及快速聚合；检查 Full 与 Narrow 截图。

复查重点：身份稳定、演示不覆盖实时数据、离线无陈旧数值、混合设备统计正确、聚合不掩盖故障/预警、局部动画与命中区域一致。
