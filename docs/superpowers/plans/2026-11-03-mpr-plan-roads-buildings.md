# MPR 平面路网与建筑几何修复

> **For agentic workers:** Use subagent-driven-development; isolate outline extraction, context geometry and planting measurements. Only the main worker mutates UE.

**Goal:** 按用户 2026-11-03 的建筑路网及全部元素轮廓重建场地关系，消除歪房、错误路口和退距问题，保留主仓内部。

**Architecture:** 最新平面图使用独立的像素到 CAD 平面映射。道路由实际边界多边形生成，不再由固定宽度中心线代替。建筑用正交局部结构、旋转和平移，绝不以双线性变形扭曲屋顶和墙体。图 2 提取树冠点位；所有空间检测使用同一平面数据。继续使用现有版本化源、分区网格/HISM 和安全导入流程。

**Tech Stack:** Blender 5.2、Python/NumPy/Pillow、Shapely、UE 5.8、FBX、现有资源所有权和内部保护工具。

**Spec:** 用户给定 `building-road-outline-20261103.png` 为最新建筑和非铁路路网几何依据，`all-elements-outline-20261103.png` 为元素布局依据；原彩色效果图保留材质/光照参考意义。更早的 `road-outline-20261103.png` 仅辅助识别，不能与新平面图直接叠加；其道路位置并不完全一致。

## 约束与根因

- 主仓内部保持原对象、GUID、组件、实例变换和依赖资产字节；主仓 CAD 尺寸为平面配准锚。
- 新图是二维平面布局，不能用原透视相机的逆投影解释建筑四角。示意图并非测量数据，局部形状不一致时保持合理三维构造与内部接口，不扭模型。
- 旧住宅将透视图屋顶四角反投在同一平面再双线性扭曲整个网格，导致大多数房屋墙角不正交、坡面不共面。新生成必须消除此路径。
- 道路口、绿化岛和真实开口分开记录；分割用的临时 gate 不能变成实体路缘封口。
- 新路网必须检查建筑侵入、树冠/树干退距、车辆铺装及入口连通；旧不受影响的元素保持原样。
- 用户已确认铁路按图 2 一起校正，与路网、建筑使用同一平面坐标；保留真实轨距和既有轨道细节模型。
- 不开发 MPR 页面，不混入 `Test.uproject` 等用户已有修改；验证后自动本地中文提交。
