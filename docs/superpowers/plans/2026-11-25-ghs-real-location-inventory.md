# GHS 真实库位库存接入实施记录

目标：接入用户提供的 2026-11-25 GHS 静态库存快照，按真实库位判断有货/空位，点击展示库位档案和 SKU 库存明细。保留现有视觉风格和场景布局。

## 数据与边界

- 原始 CSV、字段说明和 DXF 位于 `D:/Data/仓库数据/GHS`；不修改源文件。
- 91,106 个库位档案不等于场景物理容量；包含临时、虚拟及多套命名，不能强行合并编码。
- 按仓库 ID + 库位 ID 聚合，以总库存判断空位；可用为零但存在冻结/分配库存仍为有货。
- 未关联库存记录表示本次快照无库存记录；负数/缺失/冲突不能解释成空位。业务状态枚举保持原值。
- 绑定必须有 CAD/WMS 依据。无法唯一核实的场景位置显示未匹配，禁止按相近名字或任意顺序猜测。
- 用户要求自行判断映射；补充的完整匹配方案用于核对规则，没有提供地堆正式对照或现场实扫确认。自动绑定标记为规则推断，不冒充现场确认。
- 不部署服务器；保留手动地图与配置修改；验证后仅提交本任务文件到 master。

## 方案

离线聚合 CSV，输出轻量库位索引和 128 个确定性明细分片；前端仅在库存页面载入索引，点击时读取对应分片。场景使用 CAD ID + 槽位层列的明确映射查找库位，不依赖 Actor 名称。避免逐帧扫描 CSV 或向每次场景快照塞入全部库存。

## 步骤与验收

- [x] 审计 CSV、CAD 属性/文本、现有几何映射，记录可核验范围和未匹配原因。
- [x] 测试并实现导入器：多明细汇总、前导零、冻结库存、无记录、零/负/缺失、重复与跨仓冲突。
- [x] 库存页面显示真实快照库位状态、分页搜索和详情；未匹配库位可查数据但不伪造场景定位。
- [x] 对规则匹配的货架接入场景点击详情，并标明物理对应待复核；版本、变换或网格不符合契约时不继续展示旧业务库存。
- [x] 以现有槽位材质索引驱动空位显示，保持空位可点击和 HISM 顺序不变；未知槽位不当空。
- [x] 验证真实数据总量/映射覆盖、UI 安全与交互、UE5.8 编译与选择回归；核查图层/屋顶/回放不被破坏。
- [x] 保存审计、验证和未解决映射事项，中文本地提交。

当前结果：21,243 个货架托位按 CAD 排/档/高度、WMS 完整编码/库区/档号/层号推导，9,855 有货、11,388 在本次快照中为空。11,343 个场景目标仍未匹配，其中包括全部 7,530 个地堆。详细规则和与用户补充方案的差异见 `Tools/GHSInventory/README.md`。

实际渲染发现并修复：打包为 18 位整数的显隐数据经顶点插值后可能略小于原整数，直接向下取整会翻转低位，形成货物噪点残影。材质先恢复最近整数再解码，保持货物整体显示/隐藏。原始材质和地图不修改。

## 最终验证

- UE 5.8 TestEditor 编译通过；33 项原生测试通过，覆盖库存字段、冻结库存、位掩码、空位射线、完整变换、源文件哈希、容量、搜索与场景缓存。
- 网页测试 155 项通过；导入器 17 项、映射规则 14 项、插值精度回归 2 项通过。
- 独立真实场景 11 项验收通过：21,243 个规则绑定、CEF 实际索引及详情、空位屏幕点选、有货/空位不受演示滑条影响、零可用冻结库存仍有货、未匹配地堆不当空、追溯结束恢复、图层与屋顶恢复。地图文件哈希前后一致。
- 对比相同 SR 货架、相同相机位置的实际截图，修复后货物噪点消失。空位与有货详情另有实际截图。
- 全部验证为本地；没有部署服务器，没有现场实扫确认。
- 验证过程中出现过 dotnet/cl、UE JSON 解析和引擎 RigVM 的偶发原生崩溃，原样重跑最终通过；未修改引擎或全局系统设置，未确诊其共同原因。
