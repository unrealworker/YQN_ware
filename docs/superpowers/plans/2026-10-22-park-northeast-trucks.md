# 东北停车场与静态展示卡车

用户要求：东北停车场按新卫星近照细化；园区简化卡车沿用月台车型，关闭货箱门，增加蓝色，作为无 POI、无设备交互的静态展示。

1. 保存当前编辑器状态并备份；保留原仓库、52 辆月台车及用户对园区蓝色组件的 Cobalt 材质覆盖。
2. 保留 CAD 道路中心线和宽度，仅修正东北局部路面合并的错误填充；补齐外围泊位、中央双排和端头绿岛、无障碍缓冲与入口种植。两处西南停车场保持原布局。
3. 从月台长卡车的可编辑源派生闭门模型，逐部件验证复用；蓝驾驶室、加宽蓝腰线、白色货箱及闭门锁杆。
4. 使用共享静态实例网格替换旧简化车；根据真实整车包围盒及尾部原点校准泊位、道路和围栏净距。仅带 GHS_ParkContext 标签，禁用碰撞和 Tick。
5. 导入、保存、近景检查；独立进程重载及两分辨率运行回归确认业务注册表保持 106 设备 / 56 设施。覆盖当前评审图及验收摘要，中文提交本地 master。
