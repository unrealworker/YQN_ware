# MPR 仓库场景实施计划

**目标：** 按用户 MPR 主仓库 CAD 与周边环境资料创建独立 UE 5.8 关卡，复用当前 GHS ZcoolSmartFactory 的模型、材质和相机习惯。

**范围：** 本次仅三维场景；不开发 MPR 页面、不接业务数据、不修改全球仓库目录。地址为 1001 W Middlesex Ave, Port Reading, NJ 07064。

**实现：** CAD 解析结果与展示几何分离；毫米/英寸冲突使用已标注的柱距和货架尺寸校准。主建筑、屋顶和场地采用 MPR 独立资产；兼容的货架、货物、车辆、树木及材质引用 GHS 资产；重复物件使用实例化批次。新增资源限定在 `/Game/MPRWarehouse` 和 `/Game/Maps/MPR_CAD_Warehouse`。

## 工作步骤

- [x] 解析主图层、块、单位、主建筑轮廓、柱网、货架和设备；输出精简 JSON、可复现脚本与平面预览。
- [x] 解析周边路网与建筑，结合截图核对主仓库位置和方向，记录对齐变换。
- [x] 审核当前 GHS 实际模型、材质和灯光，建立复用清单；不修改共享资产。
- [x] 在独立 Blender 文件生成缺少的 MPR 建筑/场地/设备模型，保留源文件与导出数据。
- [x] 创建独立 UE 关卡，导入新增几何并实例化复用资产；按建筑、仓储、设备、道路、景观分类。
- [x] 校验尺寸、数量、坐标轴、引用、资产范围及无重复/无 GHS 业务标识；重载关卡并验证室内、室外和道路画面。
- [x] 记录待实测尺寸和视觉简化；本批次仅提交已验证场景及必要来源/脚本，使用中文 Git 提交。

验收证据：`SourceAssets/MPR/validation/README.md`。RTX 5060 Laptop、1080p 本地单进程两视角各采样 15 秒，平均帧耗时外景 6.965 ms、室内 10.319 ms；已验证共享相机接口和运行时材质，未测像素流并发。

## 验收重点

- CAD 标头 INSUNITS=4 与实际英寸尺寸冲突，不可按毫米直接导入。
- 剔除主平面外的立面、设备详图和表格，不将它们作为仓库内容。
- 外壳/屋顶保持独立，便于查看内部；墙体保持厚度与开口。
- 主建筑轮廓与周边道路正确对齐；环境资料不明的部分标明近似，不能宣称测绘精度。
- 保留 GHS 原关卡、共享模型材质及用户其他未提交修改；MPR 标签不触发 GHS HUD/车流。
