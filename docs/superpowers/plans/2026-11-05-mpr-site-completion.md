# MPR 场地完善实施计划

**Goal:** 完成两轮同机位的 MPR 外围视觉完善并提供原生运行验证。

**Architecture:** 直接在现有 MPR_CAD_Warehouse_B50B57 关卡调整光影材质、添加场地几何并组织实例，不新建关卡。复用现有 UE Python 导入、原生截图和 CSV 性能工具。

**Tech Stack:** UE 5.8.4、UE Python、Blender Python（按需生成新增网格）、现有仓库模型与验证工具。

**Spec:** ../specs/2026-11-05-mpr-site-completion-design.md

## Global Constraints

- 全部源码、资产和提交在 master，不创建分支或 worktree。
- 原 B50B57 地图备份到 Saved，内部构造和外围主路不改变，共享资产保持原样。
- 两轮同镜头，1920×1080，实际 UE 游戏帧与 CSV 数据。

## Review Focus

- 新增路缘和树木不得挡住车库门、转弯带和车位。
- 地面分层无闪烁和穿插，平面铺装不出现悬空边缘。
- 阴影柔软但仍能读出边界，屋顶不可过曝丢失光伏结构。
- 树冠饱满且色彩统一，近景可辨轮廓，远景不产生碎点噪声。
- 原关卡备份/共享资产保护，新增引用完整，重载后仍有效。
