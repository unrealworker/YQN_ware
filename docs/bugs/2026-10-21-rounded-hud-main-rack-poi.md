# 圆角 HUD、总览标题和货架区域点位

目标地图：`/Game/Maps/GHS_CAD_NormalWarehouse_ZcoolSmartFactory`。

## 用户确认的样式与行为

- 仅保留新设计的 12px 圆角，取消淡蓝渐变。原生 HUD 普通白底、选中纯蓝底、状态颜色和图标保持；类型按钮保持原白底及选中蓝边。
- 左上角按 Pencil 恢复“GHS 仓库 / 全部区域”路径、“仓库总览”标题和“按类型查看”说明。标题不是复位按钮，点击标题不穿透模型、不取消选中、不改变视角。
- 类型按钮的绘制和点击使用同一位置与尺寸，8px 间隙不切换类型；低高度或窄场景隐藏类型行，避免与底部业务面板重叠。
- POI 不得遮挡标题和类型区域；选中标签同样遵守，平滑移动后再次检查。
- 复位继续使用右下角控件或鼠标中键。

## 货架点位根因及修复

旧实现取全 1629 个货架的总包围盒，沿墙和月台的零散货架把中心拉向地堆。新实现从缓存的实例真实边界中识别最大相邻阵列，仅在几何变化时更新区域锚点，不增加逐帧场景扫描。

本场景主阵列为 1472 架，POI 世界锚点约为 UE 厘米 `(-15515.825, -575.719, 537.700)`。候选列表和逐帧投影共用这个锚点；全量库存计数及现有区域视角范围不变。
