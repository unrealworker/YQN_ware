# GHS 仓储数字孪生界面

实现地图：`/Game/Maps/GHS_CAD_NormalWarehouse_ZcoolSmartFactory`。在当前打开的浅色仓库地图点击 Play 即可看到新界面。原始 `GHS_CAD_NormalWarehouse` 保留原 HUD 和启动配置。

## 已实现

- 总览、库存、订单、设备、告警、追溯、场景七个页面，含容量环图、订单进度及趋势、设备状态、货位矩阵、设施图表。
- 五类设备模型图片、图片放大、设备详情及状态/任务/事件切换、搜索/筛选/分页、详情返回、入出库订单切换、演示告警确认。
- 实际 Actor 与场景坐标绑定：106 台作业设备、56 个充电设施；从标签发现实际稀疏 ID，不按数量伪造设备。
- 托盘与货架物料通过局部包围盒射线选择，支持无碰撞模型。货架钢结构本体不参与选择；物料细化到 CAD 实例、层、列，4px 选中角框和 POI 跟随实际对象。
- 远景 POI 聚合与避让，近景单设备标签，标签密度和图层设置；常用视角为总览、俯视、货架区域和地堆区域。
- 宽屏右栏、窄窗口底部面板；短面板横向导航，设备操作固定在底部；去除旧项目 DPI 整体缩小对新 HUD 的影响。
- 页面保留旧内容淡出 120ms，再将新页淡入 200ms；面板 420ms 完整横向滑动收展，不主动改变相机。相机位置、角度、距离共用默认 850ms 缓入缓出；模型真实中心作为旋转轴，面板构图通过相机局部偏移完成。窗口尺寸变化时重新对齐已选目标。
- 松开时主动分发视口已积累的鼠标移动量，之后再判断点击；释放先于移动轴、同帧连续按下、焦点取消均有回归覆盖。真实短拖动的验证限制见下文。

## 操作

左键点击对象或标签查看详情；左键拖动旋转，右键拖动平移，滚轮缩放。Home 返回全仓，Escape 返回详情上一级。面板内的鼠标操作不会传给场景相机。全局搜索支持设备/月台编号，以及已提供的演示物料 SKU2038、名称、型号、批次或托盘编号。

## 八项交互修订（2026-10-20）

1. 面板展开/收起只改变布局与输入区域；相机重新构图仅发生在实际视口尺寸变化时。
2. 货架钢结构不生成实例 POI，也不能打开对象详情。点击货架上的实际货物仍返回 CAD 实例、层和列；区域 POI 是独立视角入口。
3. 聚焦使用实际静态网格或物料局部包围盒的世界中心，保留真实 Z；围绕对象旋转和缩放时，目标仍对齐可用场景中心。
4. 相机移动、旋转、臂长和构图偏移使用同一 850ms quintic 时钟（区域 950ms）；途中重新定位从当前实际姿态接续，鼠标操作取消自动飞行。
5. POI 对照设计稿恢复类型线性图标、42px 标签、6px 圆角、引线与椭圆锚点。选中时蓝底白字白图标，状态独立显示，不用选中蓝色冒充运行状态。
6. 选中角框为 4px，角臂长 24px。
7. 页面保留旧 DOM 淡出后再替换新内容，后台快照合并到动画完成后；连续切换以最新目的地为准，保留各页滚动和输入焦点，并尊重减少动态效果设置。
8. 常用视角删除入库/出库月台，换为货架/地堆区域，使用对应场景图片，并按该区域实际实例包围盒定位。

## 数据边界

场景身份、实例及坐标为真实项目数据。已有叉车/堆高车初始化演示状态继续保留，带有演示标识；已接受的实时遥测不会被覆盖。未接入的 AGV、设施或装卸车字段显示“未接入 / —”。

库存 2400 托位、今日订单 284 单、SKU2038 的库存/分配/可用数量及演示告警属于设计样例，页面有来源标记。本任务没有提供 WMS、WCS 或历史轨迹服务；实际 CAD 货位不自动绑定示例 SKU，查看演示物料有独立入口。模型预览是项目渲染图片，不是实物照片。
