# GHS 追溯行驶线稳定性修复（2026-11-26）

待行驶线的边缘和尾部曾使用随帧变化的时间抖动遮罩；冻结镜头和回放时间后，细线仍明显闪烁。64 倍速还会将虚线的视觉流动加速 64 倍，造成采样混叠。

现改为深度测试开启的确定性透明覆盖，保留主题蓝渐变、18 厘米线宽、虚线间隔以及已行驶部分裁剪。重叠路线使用固定绘制顺序。车辆、剩余距离和事件仍按回放倍率推进；视觉流光使用独立常速时钟，暂停冻结、倍率切换连续、拖动时定位到指定回放时刻。

## 验证

在同一设备、相同任务时刻和世界位置上拍摄实际 UE 画面。测试覆盖暂停近景、暂停远景、移动镜头以及 1 倍和 64 倍速，新版共 42 张截图。以相应关闭路线的画面识别蓝线像素，移动镜头按地面投影逐帧对齐。
