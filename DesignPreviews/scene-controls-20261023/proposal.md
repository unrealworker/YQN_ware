日期：2026-10-23。此文件与同目录 `index.html` 是独立设计提案，未覆盖正式 `Saas.pen`、当前设计索引或产品页面。只有增加道路行驶车辆已经获得先行开发授权；本方案其余部分等用户确认后再更新正式设计和项目。

## 界面

沿用现有白底、灰蓝文字、细线分隔、工业蓝强调色。四个图层开关开启底色使用项目品牌蓝 `#356BFA`，关闭底色使用浅灰 `#D8E0EC`，滑块保持白色。保留常用视角、图层、标签密度，新增“场景库容”。所有开关与滑条即时生效，删除原“应用到当前视图”，底部只保留“恢复默认”。预览可操作，左侧仓库为交互示意，不是修改后的 UE 场景截图。

| 控件 | 建议语义 |
| --- | --- |
| 建筑外壳 | 主厂房外墙、屋顶、玻璃及对应附属面，不控制周边民居、道路或地面。 |
| 货架与货物 | 货架钢结构、货架托盘货物与地堆货物。 |
| 作业设备 | 当前业务装卸车、叉车、AGV、充电设施及对应效果；不包含装饰车流和停车场小车。 |
| POI 标签 | 包含主仓库入口、区域和内部设备标签；关闭后仍能点击可见模型。 |
| 货架库容 | 0–100%，步长 1%，默认 80%（0.8）。只调节货物展示，0% 时钢架保留。 |
| 地堆库容 | 0–100%，步长 1%，默认 100%（1）。每个位置的双蓝托盘按整组显隐。 |

库容统一说明：“仅调整场景货物展示，不改变实际库存。”不修改已核验的库存、台账和业务饼图；库容是视觉演示控制，不能冒充实际仓储占用率。百分比表示完整槽位集合中的展示目标，最终数量会按整数槽位取整。

## 状态与交互

- 建筑外壳关闭：若屋顶仍关闭，先复用 0.5 秒浅蓝开顶，完成后隐藏外墙；此过渡期间保持内部标签与拾取锁定。再次打开建筑外壳，恢复墙体和立面，屋顶保持已开顶状态，不突然遮盖正在查看的内部。
- 开顶期间快速反向切换建筑外壳、全仓复位或恢复默认，以最后操作为准。开关目标即时更新，外墙显隐在开顶完成后按最新目标执行；取消旧的延迟隐藏和待执行定位，不允许迟到回调覆盖新状态。全仓立即恢复闭顶；恢复默认保留正在进行的开顶，但清除其旧附带动作。
- 屋顶存在时所有内部标签和拾取仍被禁止。封顶状态拖动滑条不自动打开屋顶，数值可调整并保留，提供“打开屋顶查看”入口。主仓 POI 只在建筑外壳可见、屋顶闭合、POI 开启时显示。
- 货架与货物关闭时，滑条置灰但保留比例；打开时恢复此前比例。被比例隐藏的货物不可鼠标命中。隐藏当前选中对象时，立即清除其角框和对应详情，不让业务刷新重新选中它。
- 主动从页面定位设备时，显示对应作业设备图层，并用轻提示“已显示作业设备”；随后按原有先开顶、后定位流程处理。此主动定位是图层偏好的明确临时变更，开关同步变为开启。真实台账尚未映射到场景的记录仍不提供定位。
- 全仓复位：恢复建筑外壳与完整屋顶，清除选择并返回园区视角；保留货架、设备、POI 偏好和两项库容值。若 POI 偏好关闭，复位后主仓 POI 也不显示，仍可以直接点击屋顶。
- 恢复默认：四个图层开启、标签密度标准、货架 80%、地堆 100%；不移动相机，不改变屋顶当前开闭状态。此操作不是“全仓复位”。
- 常用视角中的货架/地堆区域会显示对应层、先开顶再定位；普通俯视只改变视角，不隐式打开屋顶。
- 所有控件只影响本次会话。是否需要持久保存偏好留待后续；默认启动仍为完整屋顶与指定 80% / 100% 展示值。

## 道路端口

图中横挡是原道路末端的路沿/人行道端帽；后续道路延长后，端帽仍横在接缝处。确认后只在道路延长口局部移除横跨车道的路沿和封边，保留两侧路沿、道路高度、标线、现有交通路线、绿岛以及用户地面材质。不会删掉整段道路，也不修改园区围栏的有效边界。

原位修改几何生成规则中的开口，不靠叠加同色板遮挡。对两端延长口分别检查车辆路面接触、路面连续性和远景渐隐过渡。

## 性能落地方案

当前货架 `_Occ70` 网格的钢架、托盘和纸箱已合并，部分货物离线删除；直接隐藏现有货架实例既会删掉钢架，也无法补至 100%。需要先离线准备全量货物槽位和可控货物资产，沿用实例化绘制，钢架单独保持稳定。现有参考为 1,629 个货架实例、25,056 个完整货槽、7,530 个地堆位置；开发时需用当前保存资产复核，不把原网格与 Occ70 元数据相加。

每个槽位分配稳定排序/阈值，调小再调大恢复同一批位置，不在每次滑动时重新随机。地堆的两层蓝托盘属于同一展示单元。货物各 LOD、阴影和 CPU 选择判断共享相同可见性结果。

优先评估独立货物材质参数控制展示阈值；拖动时最多 30 次/秒向 UE 传最新值，UE 每帧只接受最新目标，松手立即提交最终值。避免逐帧扫描全场 Actor、增删 Actor、清空再创建实例、重建 HISM 树或重新生成业务目录。

材质遮罩仍有顶点和阴影成本，完整资产也可能比当前 Occ70 几何更重。必须测量 0%、默认比例、100% 和持续往返拖动的 Game/Render/GPU 帧时间及尖峰；必要时采用预分组显示、LOD 与批处理优化。不能仅凭“使用 Shader”声称零成本或已保证不卡顿。先做实际满载与拖动验收，再认定性能达标；本机结果不代替服务器每人独立会话的性能测试。

拖动性能对比使用同一镜头、同一车流密度和同一分辨率，先采集静止基线，再采集连续往返拖动。分别记录新增 Game/Render 开销、帧时间分位数与峰值，单列超过 50ms 的长帧及其相对基线的增量；排查滑动引入的长帧，不把已有场景负载误归为控件成本。
