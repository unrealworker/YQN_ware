# 订单场景回放 · 交互设计预览

入口为 [index.html](index.html)。本目录是一份独立、可丢弃的 HTML/CSS/JavaScript 设计预览，没有修改 `Saas.pen`、现有前端或 UE 工程。正式功能和场景实现边界以根任务的 `proposal.md` 为准。

## 当前可评审内容

- 沿用现有 64px 深蓝顶栏、四方格品牌“GHS 仓储数字孪生”、左上 GHS 选择器和 Windows Ctrl K 搜索提示。布局从左到右为场景、窄导航、业务面板；订单回放归属“追溯”。颜色为 `#172333` / `#F4F6F9` / `#356BFA` / `#25364B` / `#536478`，橙色待处理，红色故障。
- 区间默认 08:00–09:00 共 1 小时，提供 1 / 2 / 4 小时快捷长度。按仓库时区 `America/Los_Angeles` 解析，最少 1 小时。夏令时跳变中不存在的时刻报错；手填重复时刻采用较早一次；快捷时长跨越重复小时仍保留实际时长，并在区间说明中标记。时间是测试输入，不表示业务查询证据。
- 任意有效区间返回同样的 `TEST-OUT-001` 至 `TEST-OUT-004`。任意入口均展示该区间完整 5 台人工叉车和 3 个装卸车槽，不按入口订单筛设备。
- 支持运行、暂停、±30秒、1×/2×/4×/8×/16×/32×/64×、事件跳点、拖动时间轴、设备跟随和取消跟随。±30秒保持原播放或暂停状态；拖动时暂停，松手恢复原状态，到区间终点则保持完成暂停。事件点击始终暂停。
- 设备与关键事件两个标签页；事件按 12 分钟波次浏览。长区间的时间轴聚合代表标记，完整事件仍可按波次访问。
- 跨页、全仓、Home、中键和全局搜索会先暂停并显示退出确认。取消恢复进入确认前的播放状态；确认先结束回放，再恢复普通场景并进入目标页面。普通页面内容只作衔接占位。
- 手动结束保留查询区间与四条订单。完成后停在区间终点，不自动从头循环；可向前拖动继续查看，或明确点击“从头回放”保留当前订单和区间，从起点重新播放。

## 场景示意与正式方案的差异

真实底图和作业示意的切换位于页面最上方独立的灰色“交互设计预览”栏，不作为产品控件。实景使用已批准的最新闭顶 / 开顶地图截图，未在实际场景上绘制无法核验的设备路线。

SVG 示意中五车按相邻来源堆分配装卸位（2 / 1 / 2 台），使用固定独立送货车道和分开的回程线，起步错峰为 0 / 105 / 35 / 70 / 175 秒，转弯使用圆滑曲线。固定路径改善可见车距，但本示意未实现动态避让或真实碰撞验证。地堆下层蓝托保留，取走上层一个“蓝托 + 货物”；叉车载货只有这一托，放货时从货叉移除后计入卡车。FORK-03 每波固定故障 45 秒，原地停留再恢复。三辆满载卡车沿示意出口离场，空车从示意入口进入。

**补给闭环尚未制作。** 当前每 12 分钟波次仅制作取货、装车、驶离及下一空车进场。每波最后 2 分钟明确显示“后续补给流程 · 示意占位”和倒计时；来源堆在下一固定波次开始时恢复。它是当前预览的演示边界，不能当作正式方案已经完成回补搬运，也不表示真实 UE 动画、碰撞、门架货叉或货物转移已经开发。状态始终由查询起点和回放秒数计算，镜头位置不参与业务状态。

## 快速查看状态

在入口 URL 后添加：

| 参数 | 状态 |
| --- | --- |
| `?state=orders` | 已查询四条订单 |
| `?state=running` | 开始运行 |
| `?state=running&time=230&speed=64` | 载货阶段、64倍速度 |
| `?state=paused&time=310` | FORK-03 故障时刻，暂停 |
| `?state=follow` | 跟随人工叉车 03 |
| `?state=confirm` | 跨页结束确认，背景暂停 |
| `?state=complete` | 区间终点完成态 |
| `?state=paused&time=650` | 补给流程占位阶段 |
