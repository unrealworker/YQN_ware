# MPR 场景验收记录

2026-11-02，UE **5.8.4**，关卡 `/Game/Maps/MPR_CAD_Warehouse`。本轮交付三维场景及可编辑源模型，尚未开发 MPR 页面、业务数据和全球仓库入口。

## 画面与数据

已查看实际 UE 的外景、周边、室内、货架、分拣作业区、装卸门及设备近景共 8 个视角；另查看 2 张独立游戏进程截图，确认运行时树木和车辆颜色与编辑器一致。

- `01-exterior.png`：完整主仓与道路、停车、相邻建筑、铁路。
- `03-interior.png`：统一隐藏 4 个屋顶 Actor 后的 CAD 室内布局。
- `06-docks.png`：实际厚墙门洞、装卸门与停驻货车。
- `07-sorter-detail.png`：播种机分层格口、支架、控制箱与输送辊道。
- `08-rack-detail.png`：复用 GHS 的梁柱、交叉支撑、托盘和分体箱体。

保存后重新加载验证：384 个编辑器 Actor、300 组 HISM、4,741 个实例，101 个新网格和 10 个继承 GHS 的材质实例。主 CAD 对齐 2,867 组货架、164 根柱、72 个装卸门及 2 个驶入门；GHS 原地图和共享父材质的文件哈希保持不变。所有 HISM 材质均支持实例化，运行日志无材质 usage 缺失或默认材质回退。

## 实测性能

环境：Windows 11，Intel i9-14900HX、**RTX 5060 Laptop GPU**，D3D12；1920×1080、屏幕比例 100%、关闭动态分辨率和垂直同步。一个 `UnrealEditor -game -RenderOffscreen` 进程，每个视角暖机 15 秒、原生 CSV 采样 15 秒。截图在采样窗口之外。

| 视角 | 平均帧耗时 | P95 帧耗时 | 平均 GPU 时间 | 平均游戏线程 |
| --- | ---: | ---: | ---: | ---: |
| 屋顶关闭外景 | 6.965 ms | 7.587 ms | 6.464 ms | 1.467 ms |
| 屋顶展开室内全景 | 10.319 ms | 11.190 ms | 9.780 ms | 1.639 ms |

保留所有采样帧，没有删除峰值。外景最大帧耗时 15.211 ms，室内 21.824 ms。`GPUTime` 和真实 GPU pass 时间戳均验证有效；原生 CSV 压缩保存在 `native-profile.zip`，对应文件名与 SHA256 见 `performance.json`。

共享相机 Pawn 与 Controller Tick 保持开启。相机通过生产接口完成重置、缩放、旋转、再重置，实际 PlayerCameraManager 位姿有相应变化，重置位置误差为 0；该检查没有模拟操作系统鼠标事件。MPR 运行时未创建 GHS HUD/车流，库存、屋顶扫描、回放组件均未启动。

这是两个固定视角的本地场景性能基线，未覆盖长时间漫游、打包版本、浏览器解码或多人像素流并发。不能用这些数值承诺服务端并发容量。

## 交付边界

主平面与模型位置以 CAD 为准；未提供的立面高度、设备内部结构、屋面光伏排布及周边建筑高度属于已标注的展示估计。96 格装配书与 CAD 中的支机版本不同，适配模型格数不能作为已确认现场业务容量。

`scene_build.json`、`validation.json`、`performance.json` 保留原运行证据；`acceptance.json` 汇总数量、哈希和图像索引。报告中的 `Saved/` 绝对路径指向本机原始记录，本目录保留相同文件名的最终截图和 CSV 压缩包，便于新检出时复核。

重建保护的 14 项文件级测试通过，覆盖已保存地图/模型/材质修改的拒绝覆盖，以及清理 Saved 后继续验证归属。参见 `Tools/MPRWarehouse/test_mpr_scene_ownership.py`。
