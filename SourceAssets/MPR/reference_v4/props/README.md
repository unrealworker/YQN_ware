# MPR 共享树木与车辆

`manifest.json` 是本目录的有效资产清单。当前包含 1 个已审树木模块及 8 个车辆模块：3 种半挂车颜色、2 种轿车、牵引车、铁路货车、机车。旧 `Prototype` 文件不在交付清单中。树木来源和许可仍见 `SOURCE_ATTRIBUTION.json` 与 `LICENSE-BlenderStudio.txt`。

## 装卸车辆

场地共放置 52 组完整的牵引车与半挂车，每组通过相同 `assembly_id` 关联。牵引车头提取自项目已有 `SourceAssets/GHS_Normal/TrucksLong/dock_truck_long.blend`，包含驾驶室、玻璃、车灯、踏步与后视镜；底盘、第五轮和车轮使用共享低面几何。源 GHS 文件只读，来源哈希记在牵引车元数据中。半挂车本体不内嵌车头，`tractor_cab=false` 描述的是单个半挂车模块，不能据此判定最终组合缺少车头。

牵引车和半挂车分别以轮胎接地平面为 Z=0，前向为 +X；半挂车的 -X 端是装卸门。组合时第五轮对齐半挂车 `kingpin_x_m=6.55`，支腿收起。南侧 14 个和北侧 22 个 CAD 固定码头保持门洞对齐，北侧采用约 42 英尺、南侧约 53 英尺挂车长度。其余 16 组停在场内可用停车位。

新增车头使完整占地长于原图中单独的挂车符号。独立停车位采用 14m 搜索半径内最近的可用位置，联合检查挂车与车头，并避开道路、建筑、绿带和其他车辆。最后两个原本无法放下的位置为 `SouthStands_8`，从原图位置偏移 `[-3.5,+9.0]m`、合计 9.657m；以及 `SouthEastStands_2`，偏移 `[-8.0,+10.5]m`、合计 13.200m。全部 52 组均保留；共 11 个独立停车位有偏移，完整记录见 `../site/manifest.json` 的 `trailer_layout_audit`。上述偏移不是测绘修正，属于保证完整车辆可停放的场景调整。

## 连续列车

三条源图已占用轨道内放置 56 节连续车辆，其中 53 节货车和 3 台通用机车，分别为 16、19、21 节编组。车辆沿实测轨道曲线排列，邻车共享车钩连接位置；原图零散车顶符号只决定占用区间，不再作为每节车厢的独立中心位置。

轮对使用 12 段圆周几何；轨距为 1.435m，轮轴中心对齐轨头中心。生成器按实际轮踏面和轨头宽度检查曲线上的接触余量，同时排除车辆主体互相穿插及与道路、建筑碰撞。机车为中性低面场景模型，尺寸和不可见细节含视觉估计，不冒充特定铁路运营商或工程资料。

## 重建和验证

仅重建车辆时运行 `build_mpr_reference_v4_props.py -- --vehicles-only`。此分支打开现有已审 `.blend`，只替换车辆，检查树木顶点和已发布树 FBX 哈希不变，避免在成品树上重复缩放。完整树木重建属于独立流程；如完整重建基础 props 后仍需当前车辆，应在发布树木之后再执行车辆分支。

`transport_validation.json` 记录 6 个变更车辆 FBX 的回读三角形、包围盒误差、最低 Z、哈希和树木保留结果；它仅证明源交换文件一致。场地实例位置与空间避让见 `../validation/spatial_audit.json`，布局叠图见 `../validation/plan_alignment.png/json`。UE 实际显示另由 `capture_mpr_detail_views.py` 的整车、车轮、机车及车钩近景复核，不能用 FBX 通过替代原生画面验收。
