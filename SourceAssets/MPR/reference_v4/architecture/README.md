# MPR V4 主仓外壳与屋面

主仓保留原 CAD 的 16 段外墙轮廓、74 个门洞和内外地坪/屋面接口，不生成或修改内部地板、柱、隔墙和设备。最新实景 `../references/solar-roof-aerial-20261103.png` 是光伏形状、实际凹口及屋顶设备位置的依据，替代旧示意图中的规则化光伏。`style-focus-20261103.png` 继续用于场景色调，不能替代实景测量。

`plan_solar_v5.json` 保存 16 组实景光伏轮廓和 18 处封闭白区；许多原先被当成规则孔的空白实际连通外沿，现作为阶梯轮廓与凹口保留。实景先按中央排水线、东西方向屋边与南北屋边作测量图正射校正，再通过 7 个东侧 CAD 退台角点注册。最大锚点残差 2.10 m；这是截图测量，不是测绘精度。透视变换只用于测图，CAD 外壳、矩形模块、相机和最终截图均不被拉伸。照片中的红图钉遮挡部分，只在其局部 footprint 按可见阵列连续性补入，并在源数据记录不确定性。

提取采用 2 像素正交测量网格，保留原图阶梯和开口；1 像素细格断线清理不等于填平设备区。当前清单有 5,077 个规则视觉模块、957 条近景板带，模块完整落入允许轮廓后才放置。模块间距是建模估计，不表示真实电气容量。实景中 200 个独立屋面设备候选经 CAD 外壳边距与完整设备 footprint 避让后放置 195 个共享设备；9 个落在封闭净空中，其余含外沿凹口及非光伏屋面。原示意图 30 个设备位置不再作为新设备落点。照片文字、图钉、蓝色板块和相近影子碎片均被筛除；设备轮廓及高度仍为风格化模型。

5 个 SolarBank 各有 LOD0/1/2。近景保留板块、框架和支脚，只在约 0.1072 m 的细条间隙增加比电池片低 0.14 m 的灰蓝安装槽；不覆盖实景通道，也不增加与电池片共面的顶盖。中远景通过 0.055 m 闭运算合并亚像素板缝，再裁回同一真实轮廓，所有级别保留封闭孔及外沿凹口。UE SolarBank 关闭 Nanite，不能把 LOD1/2 另外放入场景。

LOD 阈值按实际分区包围球半径缩放，70 m 参考半径的阈值为 `[1, 0.9, 0.35]`；每个分区后两级取参考值乘实际半径/70。这样不同尺寸的分区遵循同一物理细节距离，避免大分区在相同距离继续显示高密度白线。该预算仍需本轮 UE 原生缩放/转动验证，源计算不能证明视觉已经通过。

`mpr_reference_shell.blend` 保留可编辑分区、隐藏模块库、共享实例和打包贴图。最新 `reference_shell_manifest.json` 为 62 个 LOD0 网格、5 个 LOD1、5 个 LOD2、880 个实例；LOD0 为 137,190 三角面，LOD1/2 各 2,676 三角面，全部交换网格共 142,542 三角面。源面数不代表 UE 同时绘制的面数或运行性能。屋面仍使用 6.1 m 网格和 0.15 m 视觉板缝；码头外墙第 2、12 段蓝色上沿为 4.5 m，其余为 1.4 m，均不改变 CAD 洞口尺寸。

`fbx_validation.json` 回读实际 FBX 的边界、三角面、材质、UV 和非退化面。`pv_source_audit.json` 绑定实景照片、提取/生成脚本与布局，检查孔、通道、设备避让、分区阈值和 CAD 接口；它只是 CPU 源审计。图像注册与模块足迹叠图位于工作目录 `Saved/MPR/pv_v6/aerial_registration.json`、`aerial_measured_overlay.png`、`aerial_generated_modules_overlay.png`，最终是否归档以 `../validation/plan_validation_archive.json` 为准。

`capture_mpr_solar_motion.py` 与 `review_mpr_solar_motion.py` 比较两版各 96 个同相机姿态；每姿态停留 0.15 秒，不是真实连续录屏。掩码由当前实际轮廓和生成板带构建，边界及两版非蓝色区域被排除。分析画布已扩展，当前板带覆盖比例读取本轮报告的 `analysis_plane.strip_area_coverage_fraction`；边缘与设备孔由原生近景补查，共同蓝面比例另随姿态记录。另有 24 个远景固定姿态采样，同样不是连续录像。统计降低不能独立证明没有闪烁或细节完整。最终原生审查前不沿用上版截图结论。

生成入口为 `Tools/MPRWarehouse/build_mpr_reference_shell_v4.py`；测量入口为 `extract_mpr_plan_solar.py`。布局沿用现有 plan 像素作为交换格式，经 `mpr_plan_layout.py` 转为 CAD 米制。源几何/相机检查不能称为整场完美 1:1。
