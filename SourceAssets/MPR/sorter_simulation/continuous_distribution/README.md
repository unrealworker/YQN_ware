根据用户 2026-11-09 的现场说明，中央传送投放设备在上料、分拣、投放、空载和分拣结束后均持续循环，只有显式暂停/停机才停止。修正上一轮将任意载具作业阶段误当作整条环线停顿条件的实现。

立柱沿固定轨道匀速循环，升降托盘与侧向短带并行工作。上料动作在工位上游提前开始，使移动托盘经过固定投放口时接到货物；投放动作同样提前开始，到达支线连接口时完成交接。接口拒收时保留原包裹并收回，继续绕行，不停整条环线。独立上料开关关闭后，已在途包裹继续分拣，清空后仍空载运转。

六位上料人员均参与供包，按累计供包数量轮转，避免上游工位占满所有空载具。允许每个目标有有限个在途包裹，并根据预计到达顺序分配，保持包裹唯一 ID 和入机顺序。整组料框车满载更换流程保持接入。

当前展示参数：主环线 96 个载具，另一组 24 个；速度 90 cm/s，上料动作 0.9 秒，侧向投放及空托盘回升各 0.3 秒，每目标最多 8 个在途包裹。动作时长不等于持续人工吞吐，投放间隔受载具到位和下游容量影响；这些数值不是厂家实测参数。

运行原 `/Game/Maps/MPR_CAD_Warehouse_B50B57` 即可看到修改。没有新建关卡；该关卡已有仿真 Actor 在运行时生成机构和人员。当前地图、材质及编辑器设置中的用户改动单独保留。

验证入口：`Tools/MPRWarehouse/verify_mpr_continuous_runtime.py`；可加 `-MPRContinuousCaptureSequence` 输出两端各 8 秒、16 fps 的固定镜头预览。独立验证所有运行阶段恒速、无货/清空后循环、满仓绕行、显式暂停、六人节拍、包裹守恒和原生渲染实例。`MPR.*` 自动化覆盖调度及整组换车；最终验收数据见本目录 `validation/`。

最终验收：23 项自动化通过；在包含全部 256 位 CAD 人员的原生 1920×1080 场景中，15 秒无 JSON/截图轮询采样约 102.34 FPS。预览视频为 16 秒、16 fps 采样，保持正常模拟时间；视频采样率与运行帧率不同。六人工位动作均为 0.9 秒，90 秒样本中每位完成约 18–19 次投放，等待载具和下游容量的时间另计。人员修正到 CAD 躯干投影位置后，包裹先在工作台近侧放下，再由短带送往固定中央接口。
