# MPR 官方第三人称人物与分拣动作

原 MPR 关卡中的简化工人改为 UE 5.8 第三人称模板的 `SKM_Manny_Simple`，使用官方材质和 `MM_Idle` 基准姿态。14 个官方资产保留原路径、原始字节；来源及 SHA256 见 `assets.json`。

22 个供包岗位与 22 个换车岗位复用现有状态机。角色按同一货箱和车架的真实位置驱动双手，配合握指、屈膝、重心前移、旋身、小步接驳、放货收手及整车推拉。腿臂使用原始骨长，不通过拉伸肢体接触目标。隐藏的换车角色不更新骨骼。

人物站位由现有 CAD 空隙约束：CAD64 小幅挪步，CAD120 原地旋身。取货结束时刻由仿真事件记录，暂停、倍速和大步推进不另启人物动画时钟。整车回空在转角处收步后改变移动方向。

## 验证

- UE 原生自动化 `MPR.`：13 项通过，含全部 22 台设备的 902 个持货姿态、真实掌心接触、骨长、足底支撑和事件时钟。
- `verify_mpr_worker_runtime.py`：16 项通过；实际运行验证全部取货、转身、放货、收手、满车交接、空车返回及继续收货。
- 1920×1080 本地原生运行，15 秒 CSV 窗口：109.90 FPS，P95 10.95 ms。采样期间不截图、不手动推进仿真。
- 独立重载原关卡，892 个 Actor、96 个预览料框车及原相机保持；地图文件 SHA256 未变化，未创建新关卡。

`validation/` 包含原生报告、CSV、关键截图、7 秒 24 fps 分拣近景，以及 22 秒整车换仓视频。换仓原始采样为 6 fps，视频以重复帧输出为 30 fps；这不是实时帧率测量。

动作属于既有仓储演示流程的程序化表现，不代表厂家动作采集或 PLC 节拍。运行帧率对应本机原生场景，不是 Pixel Streaming 性能结论。
