## 机尾换车交接点延伸

本轮统一将全部 96 台车的机尾 Exit 再向远离供货端延长 **100 厘米**，生成器和 `layout.json` / `manifest.json` 已同步。端点公式为“机身半长 + 车体半长 + 原40厘米 + 新100厘米”，符号由 `-infeed_side_local_x` 决定；65厘米横向退车距离不变。

连续扫掠检查：延长100厘米时96条路线全部无静态交集；150厘米和250厘米时均有26条路线进入 `321321` 独立容器排。首次接触发生在130.4249厘米，因此本次100厘米方案距该障碍仍有30.4249厘米平面余量。最早受阻示例是 `2C9A89_BRANCH_10` 的车0，对应容器 handle `2D4544`。独立整段矩形扫掠同时确认110、130厘米仍未接触，131厘米起出现26条受阻。

扩展审计 JSON 中的 layout 哈希对应**修改前**基准，便于解释上述“延长”数值；归档清单记录更新后的 layout 哈希。这里只证明单线静态几何；不能据距离判定换车已经离开固定镜头，也没有验证第二条会车路线。
