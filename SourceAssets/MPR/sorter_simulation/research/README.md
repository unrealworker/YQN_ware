## 当前整车版本

当前实现、CAD 分组和换车边界以 [完整工作流研究](full_workflow.md)、[CAD 分类审计](cad_audit/README.md) 及 [运行说明](../README.md) 为准。

本轮保留22台长机布局，将外侧车框按原图拆为96台可更换料框车。货物从有界输送队列经人工持货进入托盘，沿主链、升降和固定滑槽入箱。整车满载后完成在途投递、本机停稳、带货退出、交接等待、新代次空车返回和对位，随后恢复供货。没有逐箱定时清空。

人工持货、停稳换车、2秒交接等待、演示件数和节拍属于展示策略。未找到本配置完整厂家操作SOP；不宣称这些策略已在MPR现场确认。订单齐套与物理满载分别处理，不使用宣传机械效率作为现场吞吐。

`生成数 = 完成入箱数 + 搬运中数 + 待供数`，`完成入箱数 = 现存车内数 + 已转出数`；整车离场交接完成才转入已收走。包裹唯一归属、车代次、缺车禁投、共享通道换车互斥、暂停复位与倍率通过对应验证。具体结果见 [本轮验证目录](../validation_full/)。
