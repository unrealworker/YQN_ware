## 已查证问题

- 原 CAD 的 3,785 条建筑 LINE/POLYLINE 与现有提取坐标逐条复核，最大差约 0.007 毫米。
- 当前关卡的 164 根柱与已选顶层 `PILLAR` 实例位置一致，误差为 0 厘米；这不等于完整柱网。后续对嵌套 `A-COL-ENCL` 的复核发现缺失柱截面和三处双柱被替代为中间单柱，详见同级 `../structure/` 增量补丁。
- 原隔墙提取器每个墙面只保留一次 `min(matches)`，丢失了六段有明确双面线的墙体；长度合计 14.29033 米、厚度约 127 毫米。已依据原图和六处局部叠图确认，均非门洞。
- 原建筑与当前 V4 外墙生成器均只处理 72 月台门和 2 地面大门，没有处理 CAD 的 80 扇人行门。
- 80 扇门均为 0.9144 米门扇。其中外墙 34 扇组成 32 个门洞，含两组双开门；原外墙墙线端点给出的门洞净尺寸为单开 1.016 米、双开 1.9304 米。不能按门扇包围盒中心或 0.9144 米直接切墙。

## 补丁范围

`mpr_interior_architecture_patch.json` 是整合入口，共十个 FBX：

- 六段缺失隔墙合并为一个新增 mesh。
- 七个私有外墙 mesh，替换现有关卡 `MPR4_Facade_02/05/07/08/10/12/15` 的 mesh 引用。原 Actor、位置、GUID、可见性、材质覆盖、文件夹和标签均应保留。
- 34 扇外部门和 46 扇内部人行门分为两个新增 mesh，带门框与把手。双开门共享门框，中间没有多余立柱。

`facade_replacements` 提供原 Actor GUID、原 mesh 路径及新 mesh 目标路径。新增三个对象放在世界原点，遵循原导入轴约定：CAD 米坐标到 UE 厘米，Y 只镜像一次。

外墙修改从现有 V4 可编辑源文件读取实际箱体与 UV，仅切除门洞范围。未接触门洞的箱体保留原始顶点、面、UV；受影响箱体按轴对齐实体分割，门洞不依靠贴图或黑色平面伪装。保留原三槽顺序 `MPR4_IndustrialBlue / MPR4_FacadeWhite / MPR4_JointSeal`；整合时复制现有组件的材质覆盖。

新增内墙与门复用当前 `Porcelain / Cobalt / Metal` 蓝白工业材质。门扇宽度来自 CAD；门扇高 2.1 米、含顶框门洞高 2.15 米和隔墙高 3.3 米沿用展示尺寸，**不是原 CAD 已测得的立面高度**。源几何的竖向尺寸不足，不能据此声称整个建筑已毫米级还原。

## 验证

`fbx_validation.json` 记录独立 FBX 再导入结果：

- 十个 mesh 三角形、材质槽、UV 均一致；包围盒最大误差小于 0.019 毫米。
- 32 个人行门洞共 288 条穿墙射线均没有误封。
- 原 74 个大门洞共 222 条穿墙射线仍没有误封。
- 七面修正外墙外包围盒与材质槽顺序不变，未切除门洞以外的构造。

这份验证只证明源几何与 FBX；关卡导入、同相机截图及运行验证由整合脚本完成。

## 重建入口与证据

- `Tools/MPRWarehouse/audit_mpr_interior_spec_20261112.py`：从原 DXF 只读核对并生成 `Saved/MPR/interior_cad_20261112/interior_truth/` 的详细审计与六处墙体叠图。
