# MPR 嵌套柱截面与入口楼梯补齐

本补丁独立于 `../architecture/` 已完成的十个 mesh，不覆盖其文件，也不修改原 V4 资产。

整合入口：`structural_completion_manifest.json`。`additions` 中两个 mesh 均放世界原点；`removals` 是六个需要删除的既有 HISM 实例，包含精确 Actor GUID、组件名、索引和预期变换。同一组件必须按索引倒序删除，并先验证变换，避免索引移动误删其他柱。

## 结构柱核对

原图的建筑底图 `2C93B4` 内含 309 个闭合柱截面。已有 164 个顶层 `PILLAR` 实例不能代表全部建筑柱网。

- 161 个原截面与当前柱位置重合，保留。
- 三个当前单柱位于原图的双柱之间，中心偏离两个实际截面各 0.2286 米。删除这三个错误单柱及对应三个蓝色柱脚，按原图补六根双柱。
- 其他 142 条缺失截面记录中，一条完全重复，五条为已绘制外包层内部的重复核心；合并这些重叠记录后，连同六根双柱共新增 142 个独立柱体，最终 303 个可见柱截面体。所有被合并的 source handle 保留在 manifest 中。
- 截面包括 304.8 毫米、254 毫米、203.2 毫米方形以及五处不等宽外包层；不统一放大为 304.8 毫米方柱。
- 柱高统一采用当前场景已有的 12.2 米，蓝色底段 0.26 米。**这些高度为现有展示约定，平面 CAD 没有提供各柱的实测高度。**

代表性错误：`2E0F65` 相邻截面是双柱，原模型 `CAD_2D4406` 却在中间放一个方柱；`2E0B69 / 2E145B` 是 x≈24 米分隔轴线两侧的 254 毫米方柱，之前没有实例。

## 楼梯核对

`A-STAIRS` 的 836 条实体包含 18 组完整的入口梯与平台，以及一个单独小方块。18 组均实际附着在南北外墙的入口位置，位于主平面布局范围，属于实际平面构造，不是独立三视图例。没有证据显示仓内另有内部楼梯，因此没有凭空添加。

每组从原线条提取八道踏步边线，步距 279.4 毫米、踏步宽约 1.524 米，平台进深 1.8288 米。双门组保留共用的宽平台，梯段在平台一侧。孤立小方块不建楼梯。

楼梯连接当前场景仓内地坪 0 米与室外 -1.2 米，高差分为八个 0.15 米展示踢面。扶手高 1.05 米、构件断面、踏板厚度为展示参数；CAD 只能证明平面轮廓和踏步位置，不能证明这些高度。

北侧 x≈2.73 米的一组楼梯在原图中没有对应的人行门 INSERT，也没有对应大门；本补丁保留明确的楼梯平面，没有据此擅自新增第 81 扇门或切洞。应继续用现场或立面资料确认该处是封闭旧梯还是遗漏门符号。

## 验证与未改内容

`fbx_validation.json`：两个 FBX 独立回读，尺寸最大误差小于 0.019 毫米；142 个柱顶、126 个踏面、18 个平台的接触射线通过，六个删除目标与保存的 baseline 完全一致。

审计脚本：`Tools/MPRWarehouse/audit_mpr_architectural_details_20261112.py`。
构建和验证：`Tools/MPRWarehouse/build_mpr_structural_completion_20261112.py`、`validate_mpr_structural_completion_20261112.py`。

进一步发现但未猜测重建的内容：

- 54 组窗线包含真实外墙窗、入口玻璃围合以及零散窗边线。当前规则化玻璃带不符合全部 CAD 窗位置，且旧 `MPR_OfficeGlazing` 与 V4 玻璃带同时可见；需要另做窗段测量、洞口和高度映射。
- x≈23.962 米的长双线 `A-WALL-MAS` 已进入 `WALL_68..72/74`，不是漏掉整面墙。当前仍按 3.3 米办公隔墙展示，其是否应贯通至屋面需要立面高度证据，不重复叠墙。

本补丁不改变设备、输送线、工人、货架、相机、屋顶交互或材质资产。
