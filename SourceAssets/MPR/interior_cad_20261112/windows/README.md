# MPR：CAD 窗组与局部墙洞增量

本增量根据原始 DXF 的 `A-WIND` 窗线和 `A-WALL-EXT` 窗洞侧线，替换当前场景中简化且相互重叠的玻璃带。仅修正窗与遮挡窗的局部墙面，不涉及屋顶、货架、货物、播种机、输送装置、工人、相机或运行逻辑。

SHA256：`c316aafe183162c5bef636885b59cc1000c3eecf50d8be645490b4716c6af863`。

## CAD 依据

- 102 片玻璃平面：92 条与实测窗框截面中心对齐的玻璃中心线、9 条明确的室内/推拉窗线、1 个闭合室内窗矩形。这里的 102 是玻璃片数，不是 102 个外墙窗洞。
- 41 个外墙窗洞：西侧 23、东侧 14、北侧两端各 2。每个窗洞两侧均有原图墙线证据，82 个侧线位置逐个核对；完整原始 handle 和坐标保存在 manifest 中。
- 其余玻璃位于办公室/入口内侧，保持其实际平面位置，不向外墙投影或扩张洞口。相邻玻璃合并顶/底框线并去重共用立框，避免重叠闪烁。
- 例如外窗 `2C93B4/2E0CFC` 的两端开口为 x=-169.43324～-168.41724 m；原图墙洞侧线 `2E0AD8`、`2E0C2B` 与之吻合。闭合室内窗 `2C93B4/2E09AA` 的平面为 0.9144×0.127 m。

## 高度边界

DXF 在此提供平面依据，未提供可验证的窗台/窗高标高。外窗框沿用当前 V4 展示范围 z=1.325～3.875 m；室内窗框上缘限定 z=3.2 m，以匹配当前 3.3 m 办公隔墙。玻璃厚度、框架竖向细节和外墙凹窗衬边为展示构造，不能当作施工尺寸。未因补窗擅自增加入口或改变立面高度。
