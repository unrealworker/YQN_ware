# GHS 园区参考风格重建版

园区环境正式参数以 [reference_style.json](reference_style.json) 为依据：独立冷灰蓝环境底板、中灰蓝道路、亮白路缘、浅蓝屋顶及圆润云冠树。目标关卡为 `/Game/Maps/GHS_CAD_NormalWarehouse_ZcoolSmartFactory`。园区风格阶段替换树形和林岛表现，重新配色与布光；CAD 道路、建筑、停车、车辆及 17 个非植被网格角色的几何保持。独立屋顶源文件在 [MainRoof](../MainRoof/README.md)，几何不变，仅 Roof 槽按参考色调覆盖。当前场景另已增加独立办公室玻璃立面，详见 [OfficeFacade](../OfficeFacade/README.md)；当前增量验收入口为 [OfficeFacade/Review/acceptance.json](../OfficeFacade/Review/acceptance.json)。

旧版的树木统计、绿色大底板、光照参数与成功记录不再作为当前依据。园区风格阶段的离线生成、32 项几何检查、独立保存重载、15 项运行检查与 11 张图片归档是**新增玻璃立面之前的风格基线**。玻璃立面增量已通过 16 项真实游戏运行检查，耗时 29.422 秒；其保存重载状态以 OfficeFacade 验收文件为准，不由历史基线推定。

## 云冠树与独立林岛

新树由五个大小不同的树冠团、三根支撑枝和一根主干组成，共九个封闭部分，使用平滑法线；树冠纬向细分为 12 段，单树 1,856 面。三种标准变体半径约 4.05 / 3.70 / 4.60 m，高约 8.60 / 10.80 / 8.70 m，实际摆放使用各自尺度。树冠用明暗绿色分面保持体积，短树干与树冠自然连接，不再只改旧树的法线。Trees／TreesLight／TreesDark 三类树冠网格启用 Nanite，并保留完整精度的 fallback；树位、24 岛、树冠半径和 586／332 数量不变。离线面数不是每帧实际渲染面数。

七组林带合计 **280 棵树、24 个圆角林岛、72 组林岛灌木**。各组树数为 60 / 60 / 30 / 20 / 40 / 40 / 30；林岛数为 5 / 5 / 3 / 2 / 3 / 3 / 3。岛面从 `−0.16 m` 底部抬至 `0.08 m`，具有闭合侧边和可读的接地轮廓。该布局整体取代上一版森林造型，不再宣称保留旧 510 棵树的位置。

林树中心最小间距为 **10.017596 m**。树冠避让道路、建筑／车道、园区和水道，策略净距分别 `8 / 10 / 8 / 18 m`；当前实际最小值约 `11.936 / 36.714 / 58.594 / 18.733 m`。306 棵街园树也按实际冠幅检查，部分候选因避让而省略。24 个林岛不互相重叠，保留道路、水道及建筑留白。

公共道路／住宅 `scope` 以及环境底板几何保持原范围；只改变 Landscape、Trees、TreesLight、TreesDark、Trunk 五类几何。其余 17 类的顶点、三角面、包围和实例参数保持。更改的是视觉景观，不是新增测绘内容。

## 独立屋顶与后续交互

`GHS_MainWarehouseRoof` 使用 1 个多材质网格整体显隐，Blender 仍保留 431 个独立可编辑部件。几何包含 5 条分格浅蓝采光带、310 条立缝、18 个主通风帽和 2 个办公室通风口；底面 9.60 m、檐口 9.76 m、脊线 10.40 m，保留西南突出体与东南斜角。屋顶几何没有本轮重建，只有 Roof 槽颜色按 `reference_style.json.roof_color_linear=(0.80,0.88,1.0)` 调整，其他四槽保持。

办公室转角的新增立面采用外贴、不透明（Opaque）的蓝色 Fresnel 展示玻璃，配银灰分格与浅色墙柱；不会透视原有实墙。立面与屋顶为独立 Actor，隐藏屋顶不会隐藏立面。

**产品 UI 的屋顶按钮仍未实现。** 当前验证的是独立 Actor 的整体显隐；后续按钮需联动内部 POI、设备／货物选取与视角。现有业务选取使用包围盒，不会自动因为屋顶遮挡而禁用内部对象。

## 复现与保护

当前入口为 `apply_reference_style.py`、`validate_reference_style.py` 与 `capture_reference_style.py`，完整流程见 [园区扩展说明](../../../docs/ghs-park-expansion.md)。历史 `apply_park_roof_style.py`、`apply_park_forest_fill.py` 和首次部署入口不应替代本轮执行入口。

`reference_style_materials.apply` 支持连续预览，保持材质相同时复用参数缓存；最终只保存指定目标材质，不保存关卡。目标已有材质修改前备份至 `Saved/ParkReferenceStyle/Before/Assets`；初始未保存用户材质禁止覆盖。真实游戏帧发现展示卡车缺失实例化材质使用标记；7 个 Truck 材质经过 live／disk 对比，除该标记外所有已检表面属性完全一致，确认此前 dirty 来源为编辑器自动添加 usage。已备份后只补 `used_with_instanced_static_meshes=True` 并保存，不重建材质图、不改颜色或其他参数；独立保存重载已验证 7 个标记。所有关卡 Actor、相机及实例变换按本轮基线检查，只允许两处地面组件绑定和定向光旋转按当前参数变化。
