# GHS 园区补全几何

本目录是当前浅色数字孪生场景的增量园区与周边白膜模型。用户标注的完整园区为重点区域；公路、住宅和西侧河滩只作环境参照。依据用户提供的卫星图与 Google Maps 位置关系制作，属于近似视觉重建，不是测绘或宗地图。

## 坐标与导入

- 输入布局使用米制局部坐标 `u/v`，`u` 沿仓库长轴，`v` 指向装卸场地。
- Blender：`X=u−239.33385`、`Y=−(v−60.24019)`、`Z` 向上。
- FBX 使用 `axis_forward=-Y`、`axis_up=Z`，米制单位；UE 以原点、单位缩放导入。
- UE 厘米：`X=(u−239.33385)*100`、`Y=(v−60.24019)*100`。每个网格的校验边界在 `park_manifest.json`。
- 场地硬化地坪标高为 `−4 cm`，低于原仓库地坪。原仓库、货架、月台与设备均不在本生成器修改范围内。

## 内容

12 个按材质与用途合并的静态网格，共 14,996 个三角面。包含楔形装卸场地、园区环路、两个出入口门卫、西南与东北停车区、40 个挂车泊位、78 个小车泊位、Glen Helen Pkwy、Sycamore Creek Dr、I-15 双向公路、182 栋住宅白膜、200 棵低模树和 10 根灯杆。

主场景原有地面 `GHS` 标识区域（`u=189.5…277.1`、`v=147.9…159.7`）留空。新增停车与建筑均在原仓库轮廓之外；东北转弯在原有端部车辆外侧展开。
