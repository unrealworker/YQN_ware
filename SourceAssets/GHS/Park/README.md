精确轮廓保留西南办公室突出体和东南斜角，外挑 `0.25 m`；底面 `9.60 m` 对齐既有墙顶，主檐口 `9.76 m`、中央脊线 `10.40 m`，办公室采用低平屋面。屋顶含 **5 条不透明浅蓝分格采光带、310 条立缝、18 个主通风帽及 2 个办公室通风口**，距既有最高货架约 `0.446 m`。屋面高度和细节依据参考风格构建，不是建筑测绘。完整说明见 [屋顶源文件](../MainRoof/README.md)。

树冠沿用现有顶点和布置，采用平滑法线、灰绿色、粗糙度 `0.85` 与高光 `0.15`。柔影仅把既有定向光的 **光源角**设为 `7°`，AO 强度为 `0.75`、半径为 `110 cm`；不增灯、不改光照强度、曝光或渲染方式。`presentation_style.json` 记录当前风格参数。

**本轮没有新增产品 UI 的屋顶开关。** 当前只具备独立 Actor 的整体显隐能力；后续产品交互必须联动内部 POI 和选取层。现有业务选取按设备／货物包围盒计算，不会自动因屋顶遮挡而停止选取，不能把打开屋顶碰撞视为完整交互实现。
