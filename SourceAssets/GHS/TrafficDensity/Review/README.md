## 实测结果与边界

- 运行时保持32个实例、4个ISM组件、6个行驶方向；进入采样时六方向分别5、5、4、5、5、5辆。
- 常规速度连续12秒按秒记录车辆数量：30、30、30、30、29、30、28、27、29、29、30、29，平均29.25辆。
- 端点回收前后完成数5→6、生成数34→35；实例仍为32，世界Actor仍为383。回收验证仅对该装饰交通Actor加速，随后恢复；该阶段不计入常规速度帧样本。
- 常规速度阶段1,390个本机离屏Slate帧间隔，中位数8.60ms、P95为9.43ms。它不是车流GPU独立成本、发布包性能或服务器“每人独立”像素流基准，不能据此承诺所有硬件都不卡顿。
- 106台业务场景设备、56个充电设施身份与地图哈希未改变。目标地图SHA256：`d7800f8796340150e397cf65fefd722af18620ccf0f1135ddb2fc8938050c0fd`。
- UE5.4 `TestEditor` 和 `TestGame Win64 Development` 使用MSVC14.38.33130编译通过，日志位于 `Saved/TrafficDensity/build-editor.log`、`build-game.log`。独立一小时模拟与UE自动化覆盖车距、上限及回收；本轮没有烘焙打包或启动像素流服务。
