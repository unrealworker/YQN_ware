# 屋顶扫描开合验收

`roof-scan.webp` 为 126 帧实际 UE 渲染结果，固定 60 Hz 模拟时间，2.1 秒：初始完整屋顶 → 点击开顶 → 内部标签淡入 → 反向恢复。预览使用清理后的业务页面。

`verification.json` 为汇总；`runtime.json` 含正常时间下的 12 项运行检查、时序样本、源材质哈希和本机帧时间。`motion-capture.json` 记录动画每帧进度。`editor-restored.json` 记录地图、视角、选择的恢复。

编译通过 TestEditor / TestGame；UE 自动化 120/120，网页测试 90/90。没有重新打包发布程序，没有进行像素流启动或服务器并发验收。本机连续开合采样存在一次 58.59ms 游戏线程峰值；不能据此承诺稳定 60 帧或推导服务器承载量。
