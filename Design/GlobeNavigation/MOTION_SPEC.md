# 全球仓库导航 · 交互与动效规范

设计文件：[SaasNew / 全球仓库导航](https://www.figma.com/design/AvRtQ9Hcbr1ttTF5dQx9Z1/SaasNew?node-id=72-3)。本轮新增页 `72:2`，不覆盖已有仓库画板。参考画幅 1672 × 941，顶栏 54，右侧导航 439，场景区 1233。

## 状态与入口

- 初始：`72:3`。浅蓝底，真实地球，白色 GHS POI，仓库列表与选择引导。
- 选中：`72:45`。POI 变品牌蓝，球面锚点显示光环，侧栏显示仓库详情。
- 进入：`72:88`。指向 GHS 地理锚点的镜头推进、天空色遮罩和仓库首帧衔接。
- 第一击 POI / 列表项选择仓库；再次点击已选 POI 或「进入仓库」进入。以独立进入按钮避免误触，兼容参考图双状态。
- 选中后，点击地球空白区域取消选择；5px 内的指针抖动仍算点击。超过阈值后始终按拖拽处理，即使回到起点也不取消；释放在标签或控件上、取消捕获和窗口失焦也不取消选择。
- N 与底部重置箭头均发送 `home`，恢复北美初始视角；四键主栈不再把全屏图标当作重置入口。
- GHS 地址：17335 Glen Helen Pkwy, San Bernardino, CA 92407, United States。经纬度以引擎侧核验的地理数据清单为唯一来源，UI 不手写像素定位用于运行时。
- `337,783` 和 `80.0%` 是用户参考图中的设计示意值；未获得实时业务数据时运行时显示 `—`，不能当作生产指标。

## 动效时序

| 触发 | 时长 | 运动 |
| --- | --- | --- |
| 初始静置 | 连续 | 地球经度方向每秒 1.5° 微旋转；纬度轴不漂移。 |
| 开始拖拽 / 滚轮 | 当帧响应 | 立即暂停自转，复用现有相机输入与惯性逻辑；释放后 2 秒未操作开始在1秒内缓慢恢复。 |
| 选中仓库 | 320 ms | POI 背景/边框过渡；详情 opacity 0→1、translateY 12→0；选中期间暂停自转。 |
| 鼠标悬停 POI / 列表 | 160 ms | 上浮最多 2 px，边框强调；不改变地理锚点。 |
| 按下按钮 | 90 ms | scale 1→0.98；释放 180 ms 回到1；无大幅回弹。 |
| 进入仓库 | 约 4400 ms，加载时间另计 | 原生飞行约2800ms：工具先退，60ms后标签退，80ms后侧栏退，120ms后顶栏退；先沿球面转向目标再下降，68%–95%进度覆盖天空色遮罩。仓库真实就绪后约1600ms落镜揭示。 |
| 场景加载超时 | 按真实加载状态 | 保持天空色连续背景与加载反馈；不按动画计时提前揭示空场景。失败时恢复已选状态及可重试按钮。 |
| 返回全球 | 600–900 ms | 保留仓库选择，逆向淡入地球与详情；相机恢复初始全球视角。 |

## ui-motion 使用依据

采用 `ui-motion/PRIMITIVES.md` 的共享缓动与可中断动画思想；使用 `cards/card.md` 的轻量悬停/按压、`expand/expandable-card.md` 的详情分阶段显现与稳定内容宽度、`buttons/action-button.md` 的异步 pending/error 反馈、`overlays/drawer.md` 的受限容器退场保活。地球镜头推进属于自定义三维过渡，不套用网页图片旋转冒充真实地球自转。

- `--ease-spring: cubic-bezier(0.22, 1, 0.36, 1)`：详情入场与收束。
- `--ease-snappy: cubic-bezier(0.16, 1, 0.3, 1)`：按钮反馈。
- `--ease-standard: cubic-bezier(0.4, 0, 0.2, 1)`：背景色与透明度。
- `--ease-exit: cubic-bezier(0.4, 0, 1, 1)`：内容退场。
- 避免 `transition: all`；不使用立即 `display:none` 吞掉退场；透明背景只承载HTML UI，3D场景由UE绘制。
- 预加载期间允许重新选择目标，飞行提交后锁定目标直至完成；按钮pending由真实原生phase驱动，不显示虚构成功状态或伪进度。
- 页面默认启用正常动画，遵循本次明确要求；底部提示旁「减少动效」提供持久开关，不再被操作系统的隐式偏好覆盖。开启后关闭自转和大幅镜头推进，页面保留120ms透明度反馈以及必要的加载旋转；关闭即可恢复正常动画。
- 初次收到有效原生状态后使用双RAF启动顶栏/侧栏/工具入场；详情内容按35ms短阶梯显现；搜索结果替换使用有界最多144ms阶梯。过渡只使用明确属性，不对POI坐标外层做动画插值。
- 键盘可聚焦 POI、列表和进入按钮，Enter/Space选择；Escape关闭详情或取消尚未提交的进入过程，焦点返回触发器。

## 最终设计验证

- 共4张新画板、252个节点、151个可编辑文本节点，缺失字体0；保留原3页与原有画板。
- 地球来自 Blender 真实地理资产，相机经度−84°、纬度17°；原图1400²，设计显示850²，位置(220,56)。GHS经纬度34.190629582941、−117.428430792609对应画板锚点(464.727,348.250)，使用Blender实际相机矩阵输出的投影值。
- 4条原型连接、22个带原生动效的节点；已导出5fps诊断MP4，抽查0–1.8秒10帧，确认侧栏退场、加州方向推进、天空色衔接、闭顶仓库揭示。5fps仅用于相位诊断，不作为最终运行流畅度证明。
- `verification/initial.png` 与 `selected.png` 为Figma真实导出；`entry-motion.mp4` 与 `entry-motion-contact-sheet.png` 为原生Figma时间线诊断。
- `verification/figma-acceptance.json` 记录图层数量、来源哈希与精确节点ID。

UE 实景使用透视相机20°视野、纬度方向32°俯角和动态场景区域构图；Figma中的正交渲染用于设计编排，不与运行时逐像素重合。运行时POI始终由同一真实经纬度和实际相机投影生成，不为追齐参考图像素而移动仓库地理位置。

最新页面调整：地球区域左上标题与副标题已移除，不再参与入退场。顶部保留两行真实北京时间（HH:mm；YYYY.MM.DD · 星期X），以及20px时钟、28px蓝色人形头像、16px向下箭头；账户图形不绑定未实现的菜单行为。
