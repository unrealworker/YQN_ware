# GHS 仓储数字孪生 · 可交互原型

这是从 `Design/GHS_Twin_SaaS_Concept/Saas.pen` 的 54 个画板整理的独立 React 原型。保留项目主题蓝、深蓝顶栏、实际园区场景图片和既有业务口径。按用户最新指令，不新建 `.pen`，不替换原设计，不接入 Unreal 项目。

## 打开

本机预览：**http://127.0.0.1:8781/**

在本目录运行：

```powershell
npm ci
npm run dev
```

也可运行 `Start-Prototype.ps1`。顶部“页面目录”可搜索并直达 00–53 全部设计页面及状态，例如：

- `/#screen=31` 园区总览，点击主仓库 POI 查看内部。
- `/#screen=11` 库存与货位；`/#screen=12` 出入库订单。
- `/#screen=13` 设备台账；`/#screen=14` 告警。
- `/#screen=15` 追溯查询；`/#screen=47` 暂停与设备跟随。
- `/#screen=16` 场景设置；`/#screen=44` 库容说明展开。
- `/#screen=25` 本地启动器；`/#screen=35` 服务管理。
- `/#screen=42` 管理员登录；`/#screen=28` 连接进度。

## 可以体验

- ECharts 库容环图、订单趋势及分段进度：悬停查看数据，点击图例或项目进入对应业务页面。
- 库存区域搜索、货位选择、物料详情、空态与重试反馈。
- 入库/出库切换、订单筛选、详情返回保留筛选。
- 真实设备台账与场景示例分开查看；未关联设备不伪造位置。
- 告警分级、确认与处理记录；“确认”不会删除未恢复告警。
- 场景图层开关、库容滑动条、面板收起展开、搜索及仓库切换。
- 追溯时段至少一小时，任意有效时段返回同一组四个测试订单；五台叉车、三台卡车使用测试路径。
- 播放、暂停、±30 秒、倍率、事件时间点、剩余轨迹、设备选择与跟随状态；退出或跨页前确认，弹窗期间暂停。
- 像素流登录、连接进度、配置校验、在线用户管理、五秒通知断开、启停确认。登录页注明演示凭据规则。
- 页面目录覆盖原设计的业务页、详情页、连接边界、追溯状态和设计规范。

## 设计与实现边界

场景是项目真实截图，屋顶展开、设备与路线使用二维交互演示。这里没有加载 UE 场景、真实设备遥测或 Pixel Streaming 服务；服务启停、认证、会话断开仅改变原型状态。设备跟随以地图状态和选中提示演示，不是实际三维相机。

库存数量和叉车台账使用已核验的静态提取值，不是实时 API。数量单位、场景货位映射仍待确认。订单、告警、容量和回放均保留示例/测试标识。原设计中的旧本地启动器最多三位、新远端后台六位在线是两个独立示例。

## 文件

- `src/App.jsx`：整体框架、页面目录、导航确认、POI 与场景。
- `src/BusinessPanels.jsx`：五个主要业务面板及详情。
- `src/Replay.jsx`、`src/replay-data.js`：追溯交互和测试数据。
- `src/Streaming.jsx`：启动器、访问页和管理后台。
- `src/Settings.jsx`：图层与库容控制。
- `src/ui.jsx`：ECharts 封装及共用组件。
- `src/react-bits/CountUp.jsx`：React Bits 数字变化组件，库容值更新时使用。
- `public/assets/`：从现有设计源复制的真实场景和设备图片。
- `source-inventory.json`、`PAGE_COVERAGE.md`：54 个画板的文字、素材、交互要求及路由。
- `VERIFICATION.md`：浏览器检查与构建结果；`THIRD_PARTY.md`：依赖和来源。

## 构建

```powershell
npm run build
npm run preview
```

`node_modules`、`dist`、本地 QA 截图与服务器日志不纳入提交。依赖版本由 `package-lock.json` 固定。本机服务默认仅监听 `127.0.0.1`。
