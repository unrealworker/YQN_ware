# 主仓库 POI 与屋顶分层 · 设计提案

日期：2026-10-22。状态：待用户确认；本轮不开发，不修改 UE 场景、HUD 或网页代码。

唯一编辑源是同目录 `Saas.pen`，本提案使用 31–33 号画板。背景直接使用用户提供的带屋顶园区截图，保存在 `assets/warehouse-poi/roof-campus.png`。不是新增渲染效果，也不是已运行的产品交互。

## 用户要求与设计选择

用户要求：延续现在的风格；添加指向主仓库的 POI；有屋顶的默认视图不显示其他设备标签；先出设计。

本稿建议：用“GHS · 主仓库”作为唯一建筑入口，白色卡片、深蓝名称、蓝色图标与引线。点击标签先展开轻卡，用户明确点击“查看内部”才收起屋顶并切换到内部视图。两步进入、卡片尺寸和下述返回规则均为本次设计建议，尚未获准实施。

## 视觉规格

| 元素 | 规格 |
| --- | --- |
| 默认／悬停卡片 | 268 × 64，12px 圆角，白底 |
| 展开卡片 | 320 × 182，纯蓝标题区 64px，白色正文区 |
| 默认／悬停边框 | 默认 1px 灰蓝；悬停 2px `#356BFA`，尺寸不变 |
| 名称／说明 | Noto Sans SC，16px / 600；12px 常规 |
| 正文／按钮 | 14px；按钮 280 × 40，蓝底白字 |
| 主文字／次文字 | `#25364B` / `#5B6C82` |
| 定位引线与锚点 | 蓝线 1.5px，长度默认 60px；白衬椭圆 30 × 14，蓝色实心点 6px |

以上是 1920 × 1080 设计逻辑尺寸；实际显示跟随现有全局 HUD 缩放和系统 DPI，不跟随三维距离放大缩小。标签跟随主屋顶中央的空间锚点投影。展开向上增长，锚点保持不动；两张场景图的锚点均约为 (888, 414)。边缘可调整卡片位置并延长引线，但不能把真实屋顶锚点拖到其他建筑。

在安全场景区域内避让仓库选择器、搜索框、业务侧栏和导航。不显示无来源的在线状态、设备数量、告警数或库容数据。蓝点只表示建筑空间锚点，不表示设备运行状态。

## 状态与动作

| 状态 | 屋顶与标签 | 动作 |
| --- | --- | --- |
| 园区默认 | 屋顶显示；只有主仓库 POI；隐藏设备、设备聚合、区域、货位等内部标签 | 点击主仓库标签进入展开态；悬停只加深边框 |
| 仓库卡片展开 | 屋顶和镜头保持；蓝色标题、白色正文、查看内部按钮 | × 或点击空白只收起卡片；点击查看内部进入内部态 |
| 仓库内部 | 屋顶收起；主仓库 POI 隐藏；恢复内部区域和业务设备标签，按已有距离聚合与类型筛选控制密度 | 左上仓库信息附近显示固定的返回园区入口；设备点击沿用当前详情与定位方式 |
| 返回园区 | 恢复屋顶与园区视角；清除设备选择、详情、聚合展开和内部标签；重新显示唯一主仓库 POI | 恢复本提案默认状态 |

过渡建议：卡片状态 160ms；进入／返回视角约 500–700ms 平滑切换，避免硬跳；尊重减少动态效果设置。设备标签在屋顶收起且内部视角就绪后出现，不透过屋顶提前显示。屋顶切换失败时保持原视图并提供重试，不能出现盖顶且设备标签外露的中间状态。

“全仓”沿用当前视图内的镜头复位概念，不承担打开／关闭屋顶；“返回园区”才是合顶并恢复园区标签的完整动作。最终内部镜头范围与返回按钮具体布局在本提案批准后的开发中按实际可视场景核定。

## 搜索与拾取规则

- 默认隐藏类型筛选；进入内部后再显示现有类型按钮。
- 带屋顶时，内部设备和货物也不响应穿透点击；隐藏标签与禁止拾取必须一起生效。
- 输入搜索不切换视图。设备结果注明位于主仓库内，定位动作写“打开屋顶并定位”；用户执行后先进入内部，再聚焦目标并显示它的标签和详情。
- 侧栏设备定位、告警定位及其他内部对象入口遵循相同规则，不能绕过屋顶态。
- 园区静态展示卡车和周围建筑没有业务身份，不因进入内部而生成设备标签。
- Esc 优先关闭搜索或展开卡片；内部返回使用明确的返回园区入口。
