# taste-skill 图片与图表改版评审

日期：2026-10-20。设计文件：Pencil 当前文档；最新交付目录：exports/visual-v4/。23 张 1920 × 1080 画板、34 个可复用组件。

## 本轮问题和改动

上一版主要靠文字和数字说明业务，设备身份缺少图像，容量与作业进度需要逐项阅读。这次把“先识别对象，再看状态，再进入详情”作为组织原则。

| 页面 | 新增视觉内容 | 使用目的 |
| --- | --- | --- |
| 总览 | 四张指标卡、库容细环、订单状态堆叠条、五类设备状态条形图 | 同时看规模、占用和需要关注的异常 |
| 库存 | 区域容量条、48 格货位分布、选中货位卡 | 直接区分占用、空闲、锁定与选中位置 |
| 订单 | 状态占比、入库/出库累计完成折线 | 看当前积压与日内作业变化 |
| 设备详情 | 设备模型大图、电量环形仪表、任务步骤图 | 先确认是哪台/哪类设备，再判断运行情况 |
| 设备列表 | 对应设备缩略图、五类状态条形统计 | 加快识别设备类型与查找异常 |
| 告警 | 等级占比、设备缩略图、低电量仪表和关联设施图片 | 看清告警对象、阈值与下一步 |
| 充电设施 | 状态环图、设施缩略图、关联设备电量进度 | 分清空闲设施、充电设备与离线未知 |
| 物料详情 | 可用/已分配数量环图 | 480 件中 360 可用、120 已分配的结构直观可读 |
| 场景设置 | 四个真实场景模型预览缩略图 | 在切换前识别对应视角 |
| HUD 组件 | 叉车、堆高车、装卸车、充电器图片及关键进度 | 每类设备使用对应图片与指标 |

设备图来自现有项目模型渲染和场景裁图，均注明“设备模型预览”，不作为实物照片。来源见 assets/visual-v4/ASSET_MANIFEST.md。没有以通用机器人图标充当设备图片。

## 评审方法

依据 [taste-skill](C:/Users/28109/.agents/skills/design-taste-frontend/SKILL.md) 的 [app-screens](C:/Users/28109/.agents/skills/design-taste-frontend/references/app-screens.md) 与 [critique](C:/Users/28109/.agents/skills/design-taste-frontend/references/critique.md)。保留用户指定的灰白仓库、白色信息面板、蓝色数据与交互强调。按照用户参考采用四张紧凑指标卡；不加入无依据的同比/环比数字。

这次评审重点是图片辨识度、图形是否真正说明数据、比例和单位是否一致、异常能否直接看见，而不只检查页面是否“整齐”。
