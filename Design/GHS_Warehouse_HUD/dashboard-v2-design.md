# GHS 仓储物流数字孪生 · V2 空间运营总览

日期：2026-10-19。此次仅制作 Pencil 设计、静态导出和 GIF 动效示意，不开发网页，也不修改 UE 场景、相机或 HUD 实现。V1 与已有设备组件保留。全部数字、时间和定位坐标均为设计示例。

## 设计取向

以完整仓库为视觉主体，用银白渐隐阅读底、深蓝文字与细分隔组织运营信息。大标题居中，左栏回答库容与吞吐，右栏回答设备与告警，底部为当班任务。去掉重复指标和等权卡片，让不同层级的信息有不同重量。原创表达来自真实仓库比例、空间序号、业务编号和告警定位关系。

资料研究参考：

- [Webby 2026 · WWF Blue Corridors](https://winners.webbyawards.com/2026/websites-and-mobile-sites/features-design/best-data-visualization/364937/wwf--blue-corridors)：研究空间主体与数据层之间的关系。
- [FWA · Endurosat Space Service](https://thefwa.com/cases/endurosat-space-service)，条目由 [FWA 官方 RSS](https://thefwa.com/rss/) 确认：研究操作状态与空间体验的连续性。
- [Awwwards · My Little Storybook](https://www.awwwards.com/sites/my-little-storybook) 与 [Kaleidoz](https://www.awwwards.com/sites/kaleidoztm-design-website)：参考设计、可用性、创意及内容的整体完成度。未复制其版式或视觉素材。

这些参考用于建立评审标准，不表示此设计获得奖项或已完成运行时性能验证。

## 排版、色彩与响应式

- 桌面：32px 外边距，240px 信息内容栏；中央仓库完整呈现。46px 主标题、72px 库容大数、60px 在线率、30px 次级数值。正文 13—16px，必要辅助标注至少 12px。
- 笔记本：保留文字尺寸和侧栏内容宽度，压缩导航间距及场景布局，主标题 36px；底部任务行重新排布，取消微型月台矩阵。
- 手机：采用西侧月台独立取景，中文标题分两行，运营信息进入底部抽屉；重置、旋转、标签等控件触达不少于 44px。不将桌面画面整体缩小。
- 主题：背景沿用截图灰 `#C7C9CD`；主字 `#233E53`；必要辅助字 `#385468`；蓝色图形 `#285D8E`；小号蓝字 `#24557E`；运行绿 `#16876A`；小号绿字 `#12694F`；预警 `#AA6715`；故障 `#BB4744`。
- 中文采用 Noto Sans SC。状态同时使用文字和颜色，故障/预警列表提供具体原因。
- 建议断点：≥1600 为宽屏三栏；1200—1599 为紧凑三栏；768—1199 优先单侧统计抽屉；<768 为底部抽屉。当前有 1920、1440、390 三档实际画板，平板断点属于后续实现规范。

## 交互与动效规范

| 触发 | 反馈与过渡 |
|---|---|
| 按钮悬停 / 按下 / 键盘焦点 | 120ms 色彩与边框；80ms 按下；2px 焦点描边 |
| 重置视角 | 即时显示归位中，镜头目标 500—650ms ease-out，完成反馈 280ms；真实手感待开发时验证 |
| 开启旋转 | 主动点击开始，文字改为停止旋转；拖动场景立即停止，不自动恢复 |
| 专注模式 | 侧栏与任务摘要 220ms 淡出，位移不超过 16px；相机不随之重新取景，避免跳变 |
| 选中告警 | 列表保留选中态，场景显示对应设备的定位圈与紧凑详情；定位目标 450ms，定位前停止旋转 |
| 聚合 / 拆分 | 同类型、同屏幕四等分区域；低于弹簧臂阈值 10000 时不聚合。旧标签原位淡出，新标签原位淡入，120—160ms，局部位移不超过 12px；不让标签飞向区域中心 |
| HUD 详情 | 160ms 展开、120ms 收起，轻微淡入和 0.98→1 缩放，保持设备锚点；此为 V2 提案，不改变当前 UE 的既有时长 |
| 图表探查 | 80ms 显示垂线和具体时段值，离开 120ms 淡出；触控点击固定，再点击空白取消 |
| 减少动态效果 | 取消入场、自动循环和镜头过渡；保留 ≤100ms 状态淡入；用户主动开启的旋转始终可停止 |

GIF 仅演示聚合与详情的视觉节奏，不是可交互网页，也不模拟真实 UE 镜头移动。画板 14 包含默认、悬停、按下、焦点、开启、不可用六种按钮状态及图表提示示例。

## 数据口径

- 库位总量 30,000，已用 24,320，可用 5,680，使用率 81.1%。
- 入库 3,280、出库 2,960，净入库 +320。折线为每两小时托数，非累计值；06/08/10/12/14/16/18 时入库 `[280,380,460,600,520,560,480]`，出库 `[240,340,420,520,480,520,440]`。纵轴明确为 0/300/600。
- 设备 80 台：装卸车 52、堆高车 12、人工叉车 16。运行 58、待机 12、预警 5、故障 3、离线 2；在线 78/80=97.5%。手机类型表的在线数量为 52/52、11/12、15/16。
- 告警 8 条=故障 3+预警 5，未把离线 2 台重复计为告警。
- 任务 1,248=完成 1,106+进行 86+待调度 44+异常 12，完成率 88.6%。任务异常与设备告警是不同口径。
- 月台 52，作业中 34。桌面微型矩阵精确绘制 52 格，着色 34 格。
