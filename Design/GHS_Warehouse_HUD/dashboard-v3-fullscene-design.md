# V3 · 满屏场景下的桌面覆盖层

2026-10-19。按最新近景截图修订，仅设计，不开发。手机不再纳入当前方案与交付范围。V2 作为历史方案保留，当前推荐以 15—17 画板为准。

## 关键修正

V2 的裸露文字与渐隐底依赖浅灰空白区，放在近景箱体、立柱、托盘蓝线后，可读性和层级会下降。V3 将场景保持全屏铺底，网页只覆盖固定区域，不为了排版缩小场景或制造空白。

- 顶部改为 80px 实底栏，30px 居中标题与品牌、导航、连接状态同层排列。覆盖区不透出原有 HUD 残字。
- 左右统计各宽 264px，外边距 24px，固定起点 y=200；阅读底为银白 97% 不透明，辅以 18px 背景模糊，描边明确边界。中央净宽 1,344px，占视口宽度 70%。
- 库容、吞吐、任务集中左侧；设备、告警、月台集中右侧。取消跨越中央场景的任务条。
- 视角工具固定底部 588×56px；选中提示和手势提示与其中心线对齐。重置、自动旋转、设备标签、收起/展开统计均保留。
- 主动收起统计后，只保留简洁运营摘要和告警入口。相机与场景尺寸不变化，布局不因为拉近镜头自行跳动。

## HUD 与网页覆盖关系

1. 网页的顶栏、左右统计面板和底部工具是固定覆盖区；只有这些区域接收网页指针事件，中央透明区域应将操作传递到 3D 场景。
2. 普通 UE HUD 的完整显示边界与覆盖区相交时，后续实现应整项隐藏，包含图标、文字和引线；不保留半个标签，不通过持续推移标签避让。恢复显示使用少量边界缓冲（建议 12—16px）和短暂滞回，避免擦边闪烁。
3. 当前选中设备优先保留；本稿 FORK-07 位于中央，不受统计面板遮挡。选中设备落在边缘时，提供用户主动收起对应统计栏的入口；不要自动平移相机或把详情推到远处。
4. 屏幕四等分只用于同类设备聚合，沿用原约束与默认 10000 的弹簧臂阈值；与网页覆盖区是两个独立规则。
5. 收栏目标 180—220ms、透明度与不超过 12px 的短距离过渡；3D 相机和其他 HUD 锚点保持原位。镜头缩放不触发统计布局切换。

上述遮挡抑制、事件穿透和动画为设计规范，当前没有修改 UE/网页实现。静态截图无法验证任意镜头位置下的 HUD 行为；开发后需用实际投影边界验证。

## 桌面适配

当前截图高 1140，完整内容以该尺寸验证。较低高度的桌面建议将统计内容区设为独立滚动容器，面板高度为视口高度减去顶部预留及底部工具区域，保持工具固定；不能缩小全部字体或裁掉任务/告警。宽度小于 1440 时，优先保留一侧展开，由用户打开另一侧。手机端已排除。

## 视觉检查

- 第一稿暴露左上 FORK-15 标签被面板顶边半遮，固定调整双栏至 y=200 后，该标签在此近景稿中完整可见。面板位置不随相机动态变化。
- 吞吐总量标签与每两小时图表单位增加 10px 间隔，避免混淆统计口径。
- 底部三个操作区统一中心线 y=1088。
- 新增图层的文字/控件通过布局边界检查；核对近景中中央选中详情、车辆、底部 FORK-10 标签的可见性。
- 原图的既有设备 HUD 彼此遮挡不在此次网页叠加设计中修改。
