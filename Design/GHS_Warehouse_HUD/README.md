# GHS Warehouse HUD

设计日期：2026-10-16。适用场景：`/Game/Maps/GHS_CAD_NormalWarehouse`。

## 文件

- `GHS_Warehouse_HUD.pen`：Pencil 可编辑源文件，包含三张画板、可复用组件和组件实例。
- `exports/boards/01-equipment-library.png`：六类设备的详情卡、紧凑悬浮标签和锚点示例。
- `exports/boards/02-scene-overlay.png`：在项目真实 UE 场景截图上叠加堆高车 HUD。
- `exports/boards/03-states-and-guidelines.png`：运行、充电、待机、预警、故障、离线，以及深色选中卡和布局规范。
- `exports/components/`：20 张独立 PNG，2 倍分辨率，保留卡片半透明背景与透明圆角。
- `assets/`：源文件引用的项目场景截图。移动 `.pen` 时保留该目录。

## 设计方向

依据当前 NormalWarehouse 的浅灰环境、银白设备、工业蓝托盘/层板及绿色设备特效设计。主体采用半透明银白信息卡、深灰蓝文字、工业蓝识别线和细锚点引线；复杂背景提供深灰蓝选中卡。

| 用途 | 色值 |
|---|---|
| 主文字 | `#24384B` |
| 次要文字 | `#64788B` |
| 工业蓝 | `#24569A` |
| 正常运行 | `#16876A` |
| 预警 | `#A66514` |
| 故障 | `#BA4140` |
| 离线 | `#788896` |

中文使用 Noto Sans SC；编号使用 IBM Plex Mono；核心数值使用 IBM Plex Sans。

以 1920 × 1080 为设计基准，常规详情卡为 456 × 268 px，紧凑标签为 356 × 42 px。状态展示页的标签加宽至 480 px。导出 PNG 为 2 倍尺寸；实际布局使用上述逻辑尺寸。

Pencil 会把居中描边纳入导出边界，因此详情卡 PNG 实际为 914 × 538 px，紧凑标签为 714 × 86 px，状态标签为 962 × 86 px。已核对透明圆角及卡片背景的 Alpha 通道。

## 信息与状态

所有设备状态、任务号、库位号、时间、电量、速度、功率、载荷和库存数值均为设计占位，不代表当前设备遥测。六类卡片覆盖：AGV 电量/速度、堆高车电量/货叉高度、充电器功率/剩余时间、月台托盘数/进度、车辆装载量、货架库存/层级。

紧凑标签显示编号、文字状态和一个核心指标；选中展开两项核心指标和任务摘要。状态通过颜色、文字、图标共同编码。离线显示 `--` 与最后在线时间；告警条给出具体原因与建议。

这份交付是 Pencil 视觉设计与静态导出。UE 中的屏幕投影、避让、点击展开、数据绑定和动态效果需在接入时实现，文字和数值应使用可更新的 UI 元素。
