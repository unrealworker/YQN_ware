# 人工叉车 HUD 设计

日期：2026-10-19。状态：仅设计，等待用户命令后接入项目。

可编辑内容位于 `GHS_Warehouse_HUD.pen` 的第五张画板“05 · 人工叉车 HUD / 设计待接入”。总览为 `exports/boards/05-manual-forklift.png`；十张独立组件位于 `exports/manual-forklift/`。本轮没有开发 UE 组件、修改场景或编译工程。

## 信息与尺寸

- 常驻标签：34 px 高、内容自适应宽度，显示人工驾驶叉车图标、FORK 编号、状态、载荷及展开入口。当前示例宽 171–193 px。
- 详情：320×184 px；载荷和速度为主要指标，补充驾驶员工号、作业区域、任务和连接时间。
- 聚合：184×34 px；类型名称、数量与最高告警提示。成员列表宽 260 px，每页最多五台，只包含人工叉车。
- 视觉沿用银白半透明卡、工业蓝识别、深灰蓝文字；使用叉车与人员组合图标区分电动堆高车，不假定电动或燃油动力。

## 状态示例

| 状态 | 标签指标 | 详情或原因 |
|---|---|---|
| 运行 | 1.2 t | 5.0 km/h，驾驶员 OP-07，转运任务 |
| 待机 | 0.0 t | 等待派单、已停靠 |
| 预警 | 1.8 t | 接近示例额定载荷 2.0 t，90% |
| 故障 | -- | 液压系统故障，指标待确认 |
| 离线 | -- | 最后在线 3 分钟前，当前指标、人员、区域和任务未知 |

所有编号、人员、数值、任务、额定值和告警均为设计占位，不代表场景遥测或实际设备规格。未知值不会由历史数据冒充实时数据。

## 待接入时沿用的交互

实际视口按 2×2 划分，仅决定成员归属。人工叉车只与同区人工叉车聚合，每类最多四组；若未来同时显示装卸车、堆高车、人工叉车，三类合计最多十二组。类型和分区不强制标签进入固定屏幕分带，标签贴近本组投影中心，首次遮挡只做最多 40 逻辑像素的局部错开并保持稳定。

沿用 Warehouse Camera 的聚合臂长阈值，默认 10000 cm，低于阈值时逐台显示。聚合与拆分采用 120 ms 原位淡出、目标位置淡入，局部位移不超过 8 px；列表和详情开合为 220 ms。当前只展示静态设计与动效规格。
