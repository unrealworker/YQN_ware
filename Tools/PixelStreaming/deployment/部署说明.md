# GHS 仓储数字孪生 · 公网像素流部署

将整个文件夹复制到 Windows 10 服务器的普通可写目录，例如 `D:\GHS_PublicStreaming`。保留所有子目录。服务器无需安装 Unreal Editor、Node.js 或 Visual Studio。

## 第一次启动

1. 若服务器尚未安装 UE 运行库，运行 `App\Windows\Engine\Extras\Redist\en-us\UEPrereqSetup_x64.exe`。
2. 运行 `像素流服务启动器.exe`。默认程序为随包的最新 Shipping EXE，相对路径随文件夹搬迁有效。
3. 先保持“局域网”模式，点击“开始服务”，在本机打开访问地址检查画面、屋顶展开、库存、设备、追溯与鼠标操作。
4. 打开“公网配置”，按下面的方式设置公网入口。公网地址尚未提供，因此交付包没有假定任何真实 IP、域名或证书。

## 公网入口

### 推荐：域名 + 原生 HTTPS

- 为服务器配置可访问的公网 IP，在 DNS 中将域名指向该 IP。
- 在公网配置中选择“公网”，填入根地址，例如 `https://warehouse.example.com:8443`。不支持子目录挂载。
- 网页端口填 `8443`；也可以用 `443`，URL 与外部端口保持一致。若路由器做端口转换，URL 使用外部端口。
- 选择该域名的 **PEM 完整证书链**和**未加密 PEM 私钥**。私钥只保存在服务器；浏览器需要信任证书。启动器支持相对部署目录的文件路径。
- 生成至少 12 位的访问码，按需要分享给访问者。访问码、TURN 密码位于本机配置文件，不应将配置文件放到网站目录或公开分享。
- 在服务器上点击“配置公网访问”，同意 Windows 提权后为本交付目录创建防火墙规则。这个按钮不会配置云安全组、路由器、DNS 或证书。

### 已有本机 HTTPS 反向代理

勾选“本机 HTTPS 反向代理”，公网地址填写真实 HTTPS 根地址，原生证书/私钥留空。此模式播放器后端仅监听 `127.0.0.1`，将 HTTPS 代理指向 `http://127.0.0.1:8080`（按实际端口），转发 `/ws` 的 WebSocket Upgrade；保留正确的 Host，并设置 `X-Forwarded-Proto: https` 和客户端地址。

HTTPS 代理程序的 443 入站规则由服务器管理员配置；启动器不把回环后端端口开放到公网。不支持把任意远程代理标记为可信。

### 仅有公网 IP，先验证连接

可以暂时填写 `http://公网IP:8080`，不选择 TLS 证书。HTTP 会以明文传输访问码和信令，仅用于受控的初次网络检查；正式分享请使用 HTTPS。

## 视频网络：STUN / TURN

网页能打开不等于视频链路可达。配置中的 STUN/TURN 会同时发送给 UE 和浏览器。

| 字段 | 格式示例 | 说明 |
|---|---|---|
| STUN | `stun:stun.example.com:3478` | 公网地址发现；填写你可用的服务 |
| TURN | `turn:turn.example.com:3478?transport=udp` | 跨 NAT / 受限网络中继 |
| TURN TLS | `turns:turn.example.com:5349?transport=tcp` | 用于具备 TLS 的 TURN 服务 |
| 用户名 / 密码 | 由 TURN 管理员提供 | 不要使用示例凭据 |

没有 TURN 时，部分公司网络、手机移动网络会无法连接；不能把直接连接成功视为所有网络都能访问。TURN 服务和流量不包含在本包中，可接你已有/后续搭建的服务。TURN 的监听端口与中继端口范围按其自身配置开放，勿仅凭这里的示例固定放行。

| 本包端口 | 开放范围 |
|---|---|
| TCP 网页端口（默认 8080，可改 443/8443） | 浏览器到服务；本机反代模式不公开后端端口 |
| UDP 50000–50199 | UE WebRTC 媒体直连；云安全组/NAT 需匹配 |
| TCP 8888（默认） | 只监听本机，UE 到信令；**无需公网开放** |
| 动态管理端口 | 只监听本机且带随机管理令牌；**无需公网开放** |

NAT 端口转发只能使 Web 页面可达，并不会自动修复全部 WebRTC NAT 情况。手机网络测试应同时检查 TURN。

## 在线用户与断开

- 在线列表显示用户编号、访客名称、来源地址、连接时长及状态。名称由访问者填写，不是实名账号认证。
- 选中用户后点击“断开连接”并确认。仅该用户会断开；其原会话立即失效，页面停止自动重连。
- 独立模式会回收该用户的 UE 进程并释放名额；共享模式保留其他人的共享场景。
- 用户可以主动点击重新进入、重新验证访问码。这是断开当前会话，不是永久封禁用户/IP。
- 人数上限 1–10，默认 10。满员时拒绝第 11 个连接，不替换已连接的人。短暂断线会保留名额 8 秒用于恢复。
- 停止服务/退出启动器会回收本启动器拥有的进程，不按名称结束别的 UE 或 Node。

## 画质与容量

交付预设：每人独立、1920×1080、30 FPS 目标、5 / 12 / 24 Mbps 最低/起始/最高码率、最多 10 人。“按人数均分帧率”策略默认关闭，避免按人数直接压低每人的目标帧率；可按需要开启资源预算。

10 是接入上限，**不是已验证 L20-16Q 能运行 10 路的性能承诺**。每个独立视角会增加 UE 进程、显存、CPU、编码与网络消耗。先从一个连接逐步加人；监测启动器实际 FPS、GPU 显存、系统内存及出口带宽，再确定合适上限。共享模式只有一套视角和操作状态，不等于每人独立使用。

## 检查与日志

在 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Check-Server.ps1 -VerifyFiles
```

检查会输出系统、分配的逻辑处理器、内存、GPU、必要文件与交付文件 SHA256 校验。文件校验不包括可修改的 `launcher.config.json`、证书、日志和会话目录。它不会打开防火墙或启动游戏，也不能代替真实 NVENC/WebRTC 验证。

`logs` 保留启动器/服务日志；`sessions` 是运行时私有目录，正常停止会清理。交付包内不带开发机器的访问码、TLS 私钥或 TURN 密码。服务器断开远程桌面连接后也应复查串流仍运行；不要在运行期间注销启动器所属 Windows 用户。

网络原理依据：[Epic UE5.4 Hosting and Networking Guide](https://dev.epicgames.com/documentation/en-us/unreal-engine/hosting-and-networking-guide-for-pixel-streaming-in-unreal-engine?application_version=5.4)。本地验收结果另见 `验收记录.md`。
