# 启动器与接入页视觉一致性

本轮只统一已实现的 Windows 启动器、其中的服务监控、浏览器接入/加载/错误状态和搜索浮层，不新增设计稿中的独立服务器后台或账号登录功能。

## 配色与展示状态

- 底色 `#F4F6F9`，白色内容面，辅助文字 `#536478`，正文 `#25364B`。
- 主蓝 `#356BFA`；小号蓝色文字 `#2455CC`。运行/已就绪/已连接用蓝，启动等待/恢复等待用橙，停止/退出/禁用用灰，已知故障用红。
- 橙色文字 `#976025`、图形 `#D1843C`；红色文字 `#A84540`、图形 `#C85852`；禁用文字 `#6B7788`。禁用控件保留正常不透明度。
- 启动器状态色直接读取现有服务/实例状态。未识别的状态保留辅助色，不猜测为运行或故障。
- 浏览器增加仅供样式使用的 `data-state`。`ghsShutdown`/1001 为停止，已被替换/4001/4002 为退出，场景失败/超时/恢复失败为故障。等待就绪和恢复连接采用等待色。
- 会话存储、终止标记、自动重连、超时、连接名额、统计数据、按钮操作和启动器服务逻辑保持原有行为。

## 修改范围

- `launcher/LauncherTheme.cs`：颜色常量、真实状态到文字色的映射、禁用按钮与开关。
- `launcher/MainForm.cs`：端口与运行状态文字、实例状态列着色。
- `launcher/GuiSmoke.cs`：已有启动/停止截图夹具使用同样的状态色，未运行夹具。
- `player/player.css`：背景、辅助文字、状态色、操作按钮与禁用控件。
- `player/app.js`：仅增加展示状态标记并区分停止、退出与故障。
- `tests/player.test.js`：状态事件回归，同时验证原停止、替换与重连规则。
