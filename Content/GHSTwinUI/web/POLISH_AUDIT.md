# 全页面界面一致性审查

本轮覆盖七个主页面、业务与场景详情、空态、筛选菜单、说明框和图片弹窗。保留现有页面结构、导航、数据源、筛选状态与原生桥接。

## 统一规则

- 面板底色 `#F4F6F9`，数据卡片和需要区分的内容面使用白色；辅助文字 `#536478`。
- 蓝色用于选中、链接、执行/完成状态和重要数值；禁用与未接入使用灰色。
- 待处理图形 `#D1843C`、文字 `#976025`；异常图形 `#C85852`、文字 `#A84540`。文字不直接使用对比不足的浅图形色。
- 各页标题提供“数据说明”按钮。说明支持悬停、键盘焦点、点击固定、再次点击、外部点击和 Esc 关闭；关闭说明不触发详情返回。阅读说明期间暂存遥测，关闭后合并刷新最新值并恢复新按钮的键盘焦点，不自动重开说明；导航和面板隐藏仍立即响应。
- 数据未核验部分保留小型显式标记。长口径进入说明框，缺失数据继续显示“未接入 / 暂无 / —”，真实零与负数不被改写。
- 禁用控件使用可读灰色，不将整个设置区域淡化。筛选、空态、步骤条、图片弹窗和固定操作区采用同一套表面与字体规则。
